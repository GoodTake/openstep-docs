---
title: バックエンドをデプロイする
description: Console → Deploy からプロジェクトのバックエンドをデプロイする。
sidebar:
  order: 2
---

バックエンドがあるプロジェクトだけ、Console → APP に **Deploy** が出ます。

開いて **Deploy backend (Development)** をクリックします。成功すると、デプロイ済みサブドメイン（例: **Backend deployed: …**）が表示されます。バックエンドがないプロジェクトには出ません。

Preview とバックエンドデプロイは別です。ウェブ UI はまず **Preview** で見られます。API を外に出すときに Deploy を使います。
