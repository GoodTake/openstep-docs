よい依頼は短く具体的です。コーヒーショップのときのように一文から始めて、メッセージごとにサイトを磨いていけます。

1. サイトが何で、誰のためのものかを伝えます。*小さなコーヒーショップのウェブサイト。*
2. ページ、または訪問者ができなければならないことを挙げます。*メニュー、営業時間、席を予約するフォーム。*
3. こだわりがあれば加えます。名前、トーン、色、実際のメニューと価格、実際の営業時間などです。書かなかった部分は builder が妥当な既定で埋めるので、あとから変更を頼めます。
4. Enter でメッセージを送ります。改行は Shift + Enter です。

![送信前の、New agent ボックスに入力したコーヒーショップの依頼。](/images/build/start-website-1.webp)

## メッセージごとにサイトを変える

変更は一度に 1 つずつ頼み、そのたびに Preview を確認します。*予約フォームで電話番号も聞くようにして。* *営業時間を平日 8:00 〜 17:00 に変えて。* *メニューに週末ブランチのセクションを追加して。* コードの書き方ではなく、訪問者に何を見せたいか、何をさせたいかを伝えます。

## 画像や PDF を追加する

チャットボックス左下の **+**（**Attach file**）をクリックするか、ボックスにファイルをドロップするか、スクリーンショットを貼り付けます。添付できるのは JPEG、PNG、WebP の画像と PDF ファイルで、1 メッセージにつき最大 5 つです。添付したものは名前とサイズ付きのチップで表示され、削除ボタンもあります。アップロードに失敗するとチップに **Retry** が表示されます。貼り付けたスクリーンショットだけでも完全なメッセージになるので、文章を加えずに builder に見せて送れます。

## ページ上のものを指す

Preview が対応していると、Preview のツールバーに鉛筆が表示されます。クリックすると **Edit mode** がオンになり、ページ上の要素をクリックして選べます。選んだ要素はメッセージの上にチップとして表示されるので、場所を説明せずに*この見出しを小さくして*と言えます。**Edit mode** では、ページ上で直接テキストやスタイルを変えることもできます。変更を残すには **Apply**（変更した数が表示されます）、破棄するには **Discard** を押します。

## 新しいデザインを頼む

普通の依頼は、現在のデザインの範囲でサイトを変更します。まったく違う見た目を頼むと、builder がチャットボックスの上に **Redesign the visual style** を出すことがあります。理解した内容を短く添えています。クリックすると、その依頼のまま進めます。

## 知っておくこと

- 何を頼めばいいかわからないときは **Brainstorm** を選んで、builder に質問してもらいます。[Build と Brainstorm](/ja/build/modes/) を参照してください。
- builder が作業している間はメッセージを送れません。**Done** になるのを待つか、ターンを止めてください。[進捗を見る](/ja/build/progress/) を参照してください。
- メール送信や支払いの受け付けなど、ページ以外のものがほしいときは [サイトでできること](/ja/build/what-your-site-can-do/) を参照してください。
