プロジェクトが開くと、左がチャットです。ウェブアプリがある場合、右はたいてい **Preview** です。

作成時に説明を書いていれば最初のターンが始まります。そうでなければ、欲しいものを書いて Enter。

最初のターンでは次を伝えてください。

- 誰向けか、一文
- 最初に見える画面
- 必須の画面や操作（例: トークンの claim、チェックイン）

アシスタント吹き出しの下に **Thinking**、**Planning**、**Building** などのステータスが出ます。開けるようになると Preview にアプリが出ます。

**Brainstorm** では AI が質問や方針を出し、コードは変えません。方針がよければ **Start building**。[方針を確定する](/ja/agent/approve-plan/) を参照。
