ウェブサイトは **Web builder** agent が作ります。サイトを説明すると、agent が構築します。このセクションでは、最初のメッセージから公開アドレスまで、1 つの小さなサイトを追いかけます。メニュー、営業時間、席の予約フォームがある、The Cozy Coffee Table というコーヒーショップのサイトです。

1. 左レールの **+ New agent** をクリックします。**New agent** が開き、**Based on** は **Web builder**、**Build** が選択された状態になっています。
2. **Describe an app, a learning experience, or your next idea…** と書かれたボックスに、サイトの内容を書きます。コーヒーショップでは次のように書きました。*小さなコーヒーショップのウェブサイト。メニュー、営業時間、席を予約するフォームがほしい。*
3. **Build** を選んだまま、モデルも **Auto** のままにします。ボックスの下の行には **Build changes it directly.** と表示されます。
4. **Start building →** をクリックします。

![Web builder を選び、コーヒーショップの依頼を入力して Build を選択した New agent ページ。](/images/build/start-website-1.webp)

agent が作成され、メッセージが送信済みの状態で作業ページが開きます。builder は依頼から agent の名前を付けます。この例では The Cozy Coffee Table になりました。**Build** を選んだので、すぐに始まります。質問も、承認する計画もありません。

作業中、右側のプレビューカードには **Thinking**、**Planning**、**Writing code**、**Preview & test**、**Done** が順に表示されます。構築が終わると、builder の最後のメッセージに、動くようになったものが一覧されます。コーヒーショップでは、ホームページ、メニューページ、そして予約を保存するフォームがある **Book a table** ページでした。このサイトの最初の構築には約 15 分かかりました。

## 知っておくこと

- 構築には SSU を使います。残高が空の場合は、先に [SSU を入手](/ja/start/get-ssu/) してください。
- **New agent** には 3 通りで行けます。左レールの **+ New agent**、**Home** の **What would you like to build?**、Marketplace の **Website or app** カードの **Use this agent →** です。Marketplace では Web builder は **Website or app** と呼ばれ、**New agent** では **Web builder** と呼ばれます。
- builder はメニュー、価格、営業時間を自分で用意します。これらは仮の内容です。いつでも変更を頼めます。
- まだ何がほしいか決まっていませんか。**Build** ではなく **Brainstorm** を選ぶと、builder が先に質問します。[Build と Brainstorm](/ja/build/modes/) を参照してください。
- 最初のメッセージのコツは [欲しいものを伝える](/ja/build/describe/) にあります。
