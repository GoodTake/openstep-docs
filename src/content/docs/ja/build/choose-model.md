builder は AI モデルで動きます。既定では **Auto** が依頼ごとに最適なモデルを選ぶので、ほとんどのサイトではそれで十分です。自分で選びたい場合は、モードと同じメニューから名前付きのモデルを選べます。

1. チャットボックス下部のチップ（例：**Auto · Build**）をクリックします。**New agent** と **Home** では、モデルの操作 **Auto** が **Build** / **Brainstorm** の切り替えの隣にあります。
2. **Select model**（**Choose how STEPS routes this turn**）で、**Auto**（**Best model for each request**）を選んだままにするか、**Choose model**（**Pick a model for this run**）の一覧からモデルをクリックします。
3. メッセージを送ります。チップに表示されているモデルで実行されます。

![開いたチャットボックスのチップ。Select model で Auto にチェックが付き、その下に短い Choose model の一覧、一番下に Run mode がある。](/images/build/choose-model-1.webp)

モデルを変えても、それだけでは何も始まりません。次のメッセージの扱いが変わるだけです。

## 知っておくこと

- **Choose model** の一覧は時間とともに変わるため、このガイドではモデル名を挙げません。いま使えるものは、いつでもメニューに表示されます。
- builder が作業している間、チップはグレー表示です。モデルはメッセージの合間に変えてください。
- チップが **Loading models** と表示されているときは、少し待ちます。**Models unavailable** と表示されているときは、クリックして再試行します。
- 同じメニューにモードもあります。[Build と Brainstorm](/ja/build/modes/) を参照してください。
