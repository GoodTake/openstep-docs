ほとんどのサイトは何かを保存します。予約、注文、メッセージなどです。**Data** タブにはサイトが保存したものが一覧されるので、builder に頼まなくても、確認や修正ができます。

1. 右側上部の、**Preview** の隣にある **Data** をクリックします。ページのタイトルは **Data** で、テーブルごとにカードがあり、件数が表示されます。コーヒーショップのテーブルは **bookings**、**orders**、**users** です。**Search tables…** で探し、**A-Z** で並び順を変えます。
2. テーブルをクリックして開きます。上部に名前と件数が表示され（例：**bookings (1)**）、その下に行があります。**Search rows…** で絞り込み、列見出しをクリックして並べ替え、下部の矢印でページを移動します。
3. 行をクリックして変更し、**Save changes** をクリックします。行を追加するには **+ Add item** を使います。各行には削除ボタンもあります。
4. 左上の戻る矢印をクリックすると、テーブルの一覧に戻ります。

![Data タブの bookings テーブル。Preview で行ったテスト予約が入っている。](/images/build/data-1.webp)

## 知っておくこと

- スクリーンショットの予約は、[Preview](/ja/build/preview/) で予約フォームを送信したときに現れたものです。テーブルは、人がサイトを使うにつれて埋まっていきます。
- これは開発用のデータで、Preview が読み書きするデータです。[公開](/ja/build/go-live/) すると、公開中のサイトは別に独立したデータを持ちます。Preview で行ったテスト予約は公開中のサイトには届かず、公開中のサイトで入った予約はここには表示されません。**Publish** が開発用データを公開中のサイトにコピーすることはありません。公開中のデータと学習者の進捗は保持され、新しいセッションが始まることもありません。更新によってデータが消える場合、たとえば新しいバージョンにはもうないテーブルやフィールドがあるときは、先に Publish ダイアログが警告します。そのように削除されたデータは、元に戻せません。
- ここでは行を編集します。テーブルや新しいフィールドを追加するには、チャットで builder に頼みます。builder は構築の中でテーブルを作ります。
- オーナーとエディターは行を変更できます。ビューアーは見るだけです。
