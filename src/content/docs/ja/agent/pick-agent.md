Marketplace には、用意された agent が並んでいます。それぞれが特定の種類の仕事のために作られていて、必要なことを質問し、計画を立て、あなたに代わってアプリを作ります。1 つ選んで、考えていることを伝えると、自分の agent ができます。このセクションのどのページも、1 つの例 **Health & fitness** をたどります。これは Three Day Strength という名前の agent になりました。

1. 左レールの **Marketplace** をクリックします。ページの名前は **Agent marketplace** で、「Choose a product to create your own agent. Continue existing work from My agents.」と表示されます。
2. カードを見ていきます。**All agents** はすべてを、**By OpenStep** は OpenStep が作ったものを表示します。探すときは **Search agents…** に入力します。各カードには、画像、名前とカテゴリー、何を作るかの 1 行、**Use this agent →** があります。**Health & fitness** のカードには「Training plan, workout log, weight and measurements.」と書かれています。

   ![Agent marketplace ページ。agent のカードが並び、Use this agent ボタン付きの Health & fitness も見える。](/images/agent/pick-agent-1.webp)

3. **Health & fitness** の **Use this agent →** をクリックします。**New agent** が開き、**Based on** にその agent がすでに選ばれています。
4. **Describe an app, a learning experience, or your next idea…** と書かれたボックスに、最初のメッセージを書きます。ここで多く伝えるほど、agent が聞く質問は少なくなります。たとえば、*筋力をつけたい。週 3 日ジムでトレーニングでき、1 回あたり約 45 分。*
5. モードは **Brainstorm**（**Health & fitness** はこれで始まります）のまま、モデルは **Auto** のままにして、**Start brainstorming →** をクリックします。

   ![Health & fitness を選び、最初のメッセージを入力して Brainstorm を選択した New agent ページ。](/images/start/create-agent-1.webp)

agent が作成され、builder が名前を付けます。ここでは Three Day Strength です。作業ページがすぐに開き、あなたのメッセージはもう送信済みです。左がチャット、右が **Preview** と **Data** のある App ビューです。agent があなたのメッセージを読み始め、最初の質問は数分後に届きます。

## 知っておくこと

- Marketplace のカードは製品です。始めると自分の agent ができ、あなたがすることは他の人の agent を変えません。
- agent は 1 つ以上の App を持ちます。Health & fitness の agent が作る App は 1 つです。
- **Brainstorm** では、agent が質問し、計画を立て、タスクごとに構築します。**Build** では、直接変更します。[Build と Brainstorm](/ja/build/modes/) を参照してください。
- 用意された agent を使わずにウェブサイトを作るには、[ウェブサイトを始める](/ja/build/start-website/) を参照してください。
- 始めた agent はすべて、**My agents** と、左レールの **RECENT AGENTS** に表示されます。
- agent の作業には SSU がかかります。残高が少ないときは、先に [SSU を入手](/ja/start/get-ssu/) してください。
