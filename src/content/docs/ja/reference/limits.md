title: プラットフォームの注意
description: OpenStep を使うときに知っておく製品の境界。

  order: 2
---

- 構築は、プラットフォームが用意する隔離環境で行われます。始めるために自分のホストは不要です。
- チャットに **This chat got too long** と表示されたら、メッセージをもう一度送ってください。次のターンは新しく始まり、これまでに作ったものはすべて無事です。
- agent がまだ構築中の間は公開できません。ヘッダーの **Publish** は、構築が止まるまでグレー表示です。[公開する](/ja/build/go-live/) を参照してください。
- agent を公開する、誰が開けるかを変える、削除する、ができるのは、その agent のオーナーだけです。エディターはチャットと構築ができ、ビューアーは見るだけです。[他の人と作業する](/ja/agent/work-with-others/) を参照してください。
- **Publish** は agent のすべての App をまとめて公開します。1 つの App が失敗すると何も変わらず、公開中のバージョンはそのままです。
- カスタムドメインには、その時点で **Console** の **Domains** に表示されている DNS のターゲットを使ってください。ドメインは App ごとに持ちます。[ドメイン](/ja/build/domains/) を参照してください。
- アプリの公開運用と構築は、どちらも SSU を使います。[SSU とは](/ja/account/what-is-ssu/) を参照してください。
- このサイトは builder 製品を説明するものです。内部の技術仕様やデプロイ記録を、ユーザー向け文書として扱わないでください。
