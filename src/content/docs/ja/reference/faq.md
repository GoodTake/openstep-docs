**なぜ 2 回署名するのですか？**  
先にウォレットを接続し、次にログイン用のリクエストに署名します。2 回目の手順は送金ではありません。ページには **It's free — no transaction, no gas.** と表示されます。[サインイン](/ja/start/sign-in/) を参照してください。

**agent と App の違いは何ですか？**  
agent は、会話、その計画、構築をまとめて保持します。agent は 1 つ以上の App を構築し、各 App は独自のプレビュー、コード、データ、公開アドレスを持ちます。[OpenStep とは](/ja/start/what-is/) を参照してください。

**用意された agent はどう使いますか？**  
**Marketplace** で選び、**Use this agent →** をクリックします。[Marketplace から agent を選ぶ](/ja/agent/pick-agent/) と [最初の agent を作る](/ja/start/create-agent/) を参照してください。

**Brainstorm でアプリが変わらないのはなぜですか？**  
仕様です。**Brainstorm** は質問をして計画を作り、計画を承認してから構築します。アプリをすぐに変えたいときは、**Build** モードでメッセージを送ります。[Build と Brainstorm](/ja/build/modes/) と [計画を承認する](/ja/agent/approve-plan/) を参照してください。

**Preview と Publish の違いは何ですか？**  
**Preview** は下書きで、ほかの誰かが開ける前の、いまのアプリです。**Publish** は、agent のすべての App を、ほかの人が開けるアドレスでまとめて公開します。[サイトをプレビューする](/ja/build/preview/) と [公開する](/ja/build/go-live/) を参照してください。

**ほかの人にアプリを試してもらうには？**  
agent を公開して、アドレスを送ります。誰が開けるか（リンクを知っている人なら誰でも、または学習者のみ）は、**Console**、**Settings**、**Access** で選びます。[公開と共有](/ja/agent/publish-and-share/) を参照してください。

**別の通貨で支払いを受け取れますか？**  
できません。アプリ内決済は SSU のみです。[SSU とは](/ja/account/what-is-ssu/) を参照してください。

**SSU はどこに使われましたか？**  
左レールの **Balance** をクリックします。**Activity** に、構築、アプリが使うプラットフォーム機能、アプリの公開運用に対するすべての課金が一覧されます。[残高を確認する](/ja/account/balance/) を参照してください。

**自分のコンピューターで agent の作業はできますか？**  
できます。OpenStep CLI を使います。[CLI でできること](/ja/cli/what-it-does/) を参照してください。
