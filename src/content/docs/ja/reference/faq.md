**なぜ二回署名するのですか？**  
先にウォレットを接続し、次にログイン用の署名をします。二回目は送金ではありません。ページは **no transaction, no gas** と書いています。

**Brainstorm でアプリが変わらないのはなぜ？**  
仕様です。Brainstorm は相談だけです。コードを書くには **Start building** をクリックします。

**Preview と Publish の違いは？**  
Preview は編集中の下書きです。Publish がある版を、他の人が開ける URL に出します。

**別の通貨で決済できますか？**  
できません。アプリ内決済は SSU のみです。

**Agents はどう使いますか？**  
まだ開発中です。[Agents](/ja/projects/agents/) を参照。
