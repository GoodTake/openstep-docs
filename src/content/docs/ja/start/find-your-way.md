サインインすると **Home** が開きます。左レールはどのページにも表示されるので、そこからどこへでも移動できます。

![左に左レールがある Home。New agent、Home、Marketplace、My agents、Campus Earth、Members、Settings、最近の agent、そして下部に残高が並んでいる。](/images/start/find-your-way-1.webp)

## 左レール

上から順に次のとおりです。

- ワークスペース切り替え（最初は **Personal**）：作業中のワークスペースです。agent はいずれかのワークスペースに属します。
- **+ New agent**：agent を始める **New agent** を開きます。[最初の agent を作る](/ja/start/create-agent/) を参照してください。
- **Home**：開始ページです（下記参照）。
- **Marketplace**：出発点にできる、用意された agent です。[Marketplace から agent を選ぶ](/ja/agent/pick-agent/) を参照してください。
- **My agents**：自分が所有または共同作業しているものすべてを、最近動いた順に表示します。**Building** や **Live** などの状態で絞り込めます。[agent を管理する](/ja/agent/manage-agents/) を参照してください。
- **Campus Earth**：参加した学習体験です。たとえば招待されたコースがここに並びます。自分の agent は **My agents** に残ります。
- **Members**（**WORKSPACE** の下）：このワークスペースで共同作業する人たちと、**Invite member** です。[他の人と作業する](/ja/agent/work-with-others/) を参照してください。
- **Settings**（**WORKSPACE** の下）：ワークスペース名、利用状況と残高、OpenStep CLI に許可したデバイス、所有権の移譲があります。
- **RECENT AGENTS**：最近の agent です。左レールからワンクリックで開けます。
- **Balance**（下部）：SSU の残高です。クリックすると Balance ページが開きます。[残高を確認する](/ja/account/balance/) を参照してください。
- **Balance** の下のウォレット：アカウントメニューを開きます。

## Home

**Home** には次が表示されます。

- **Welcome back**。**Total agents**、**Building**、**Needs attention**、SSU 建ての **Platform balance** と **+ Top up** ボタン、そして **Wallet assets** があります。
- **What would you like to build?**：**New agent** と同じ入力ボックスです。欲しいものを書き、**Build** か **Brainstorm** を選んで始めます。[最初の agent を作る](/ja/start/create-agent/) を参照してください。
- **Recently edited**：最近の agent ごとのカードで、**Live** か **Draft** のバッジが付きます。**View all agents →** は **My agents** を開きます。

## アカウントメニュー

左レール下部のウォレットをクリックします。メニューには次が含まれます。

- **Balance**：左レールの **Balance** と同じページです。
- **Purchase SSU**：SSU を購入します。[SSU を入手する](/ja/start/get-ssu/) を参照してください。
- **+ Redeem a code**：コースコードを使います。[コードを引き換える](/ja/account/redeem/) を参照してください。
- **Disconnect**：サインアウトします。

## 知っておくこと

- agent の作業ページでは、会話と App の表示領域を広げるため、左レールがアイコンだけに縮みます。
- 自分で作ったものはすべて **My agents** にあります。参加したコースは **Campus Earth** にあります。

次へ：[SSU を入手する](/ja/start/get-ssu/)。
