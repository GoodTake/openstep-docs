---
title: 最初のプロジェクトを作る
description: /projects/new で作りたいシステムを書いてプロジェクトを作成する。
sidebar:
  order: 5
---

サインイン後、左レールの **New project** を選ぶか、`/projects/new` を開きます。

見出しは **What do you want to create?**、副題は **Describe your idea, or start from an example.** です。

1. ボックスにシステムを書く（空のまま後から話してもよい）。
2. セグメントの **Run mode** で **Build** か **Brainstorm** を選ぶ（既定は Build）。**Brainstorm** は質問のみでコードを書かない。**Build** はプロジェクトにコードを書く。[Build と Brainstorm](/ja/build/modes/) を参照。
3. 必要ならモデルセレクターでモデルを変える。
4. 上向き矢印（アクセシブル名 **Create project**）をクリックするか Enter（Shift+Enter で改行）。

例チップはプロンプトを入れる。例: **Habit tracker web app**、**Launch a token**、**Token with a claim page**。

成功するとプロジェクトエディター（`/projects/:id`）が開く。作成時に説明を書いていれば、最初のチャットとして送られる。
