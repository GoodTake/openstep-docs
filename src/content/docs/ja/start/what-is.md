OpenStep は AI フルスタックビルダーです。[builder.openstep.academy](https://builder.openstep.academy) でチャットに作りたいシステムを書くと、プラットフォームが隔離環境で構築します。プレビューも公開もできます。

最初に自分のサーバーや git リポジトリは不要です。製品を開き、ウォレットでサインインし、プロジェクトを作り、欲しいものを伝えてください。

このサイトは **OpenStep builder の使い方** です。公開したアプリができること（決済、メール、データ保存）は「アプリを作る」の短い概要であり、API カタログではありません。
