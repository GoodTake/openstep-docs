コマンドを npm でインストールし、一度だけサインインします。サインインは Chrome 上のウォレットで行うので、ターミナルがウォレットやパスワードを見ることはありません。

Node.js 24 以降が必要です。`node --version` で確認してください。

## インストール

1. パッケージをインストールします。

   ```sh
   npm install -g openstep
   ```

2. 動作を確認します。

   ```sh
   openstep --version
   ```

## サインイン

1. ターミナルで次を実行します。

   ```sh
   openstep login https://builder.openstep.academy
   ```

2. CLI がデバイス認可の URL を表示します。これをウォレット拡張機能のある Chrome で開いてください。CLI がブラウザーを開くことはありません。
3. まだサインインしていない場合は、ウォレットを接続して署名します。[サインイン](/ja/start/sign-in/) を参照してください。そのあと、ページは認可リンクに戻ります。
4. **Requesting device** のボックスを確認します。いま `openstep login` を実行したコンピューターが表示されているはずです。
5. **Authorize openstep CLI** をクリックします。ページにターミナルに戻ってよいと表示されます。

![承認前の、ブラウザーに表示された OpenStep CLI の認可ページ。](/images/cli/install-1.webp)

6. ターミナルに戻ります。サインインが確認され、コマンドが終了します。

## サインアウト

```sh
openstep logout https://builder.openstep.academy
```

これでこのコンピューターの認可が取り消されます。再び CLI を使うには、もう一度サインインしてください。

ブラウザーからデバイスをサインアウトすることもできます。左レールの **Settings** を開き、**CLI ACCESS** セクションを探します。認可した各デバイスが一覧されています。デバイスの隣の **Revoke** をクリックすると、そのデバイスがサインアウトされます。コンピューターを紛失した場合や、見覚えのないデバイスがある場合に行ってください。

## 知っておくこと

- 承認すると、ターミナルにあなたのアカウントの権限が渡ります。**Requesting device** があなたのコンピューターでない場合や、`openstep login` を実行していない場合は、ページを閉じてください。
- ページにセッションを認可できなかったと表示された場合、リンクの期限が切れているか、すでに使用されています。`openstep login` をもう一度実行して、新しいリンクを使ってください。
- CLI はサインイン情報を `~/.openstep/credentials.json` に保存します。このファイルは非公開にしてください。ソースファイルにコピーしたり、共有したりしないでください。
- 複数の OpenStep アドレスにサインインしている場合、agent フォルダーの外では、コマンドに `--origin https://builder.openstep.academy` を付けてください。agent フォルダーの中では、チェックアウト時に保存されたアドレスが使われます。
