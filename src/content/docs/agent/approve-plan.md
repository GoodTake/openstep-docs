---
title: Confirm the plan
description: After Brainstorm, Start building writes code. Keep refining stays in Brainstorm.
sidebar:
  order: 3
---

When a Brainstorm turn finishes with a plan, two actions appear under the last assistant message:

- **Start building** — the next turn runs in **Build** and writes code from the plan.
- **or keep refining** — stay in **Brainstorm** and keep talking.

This confirmation only appears after Brainstorm, not after a Build turn.

If you skip confirmation and send a new message while still in Brainstorm, the AI keeps asking questions and does not write code.
