The Marketplace lists ready-made agents. Each one is made for a kind of job: it asks you what it needs, plans, and builds the app for you. You pick one, say what you have in mind, and you get your own agent. Every page in this section follows one example, **Health & fitness**, which became an agent named Three Day Strength.

1. Click **Marketplace** in the left rail. The page is called **Agent marketplace**: "Choose a product to create your own agent. Continue existing work from My agents."
2. Browse the cards. **All agents** shows every one, and **By OpenStep** shows the ones OpenStep makes. To look for one, type in **Search agents…**. Each card has a picture, a name and category, a line about what it builds, and **Use this agent →**. The **Health & fitness** card says: "Training plan, workout log, weight and measurements."

   ![The Agent marketplace page with a grid of agent cards, including Health & fitness with its Use this agent button.](/images/agent/pick-agent-1.webp)

3. Click **Use this agent →** on **Health & fitness**. **New agent** opens with that agent already picked under **Based on**.
4. Write your first message in the box that says **Describe an app, a learning experience, or your next idea…**. The more you say here, the fewer questions the agent has to ask. For example: *I want to get stronger. I can train 3 days a week at the gym, about 45 minutes each time.*
5. Leave the mode on **Brainstorm**, which is what **Health & fitness** starts in, and the model on **Auto**. Click **Start brainstorming →**.

   ![The New agent page with Health & fitness picked, a first message typed and Brainstorm selected.](/images/start/create-agent-1.webp)

The agent is created and the builder gives it a name, here Three Day Strength. Its work page opens at once with your message already sent. The chat is on the left and the App view, with **Preview** and **Data**, is on the right. The agent starts reading your message, and its first questions arrive a few minutes later.

## Good to know

- A Marketplace card is a product. When you start it you get your own agent, and nothing you do changes anyone else's.
- An agent holds one or more Apps. The Health & fitness agent builds one.
- In **Brainstorm** the agent asks, plans, then builds task by task. In **Build** it changes things directly. See [Build and Brainstorm](/build/modes/).
- To make a website instead of using a ready-made agent, see [Start a website](/build/start-website/).
- Every agent you start is listed in **My agents** and under **RECENT AGENTS** in the left rail.
- The agent's work spends SSU. If your balance is low, [get some SSU](/start/get-ssu/) first.
