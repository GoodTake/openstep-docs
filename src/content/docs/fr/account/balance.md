---

Ouvrez le menu compte → **Credits** pour aller sur `/funds`. La page explique **Move SSU between your wallet and your Smart Account.**

Deux directions :

- **Deposit** : du wallet vers le Smart Account
- **Withdraw** : du Smart Account vers le wallet (la page affiche des frais ; l'affichage par défaut est 0.5 SSU)

Le wallet doit être sur **Base**, et l'adresse connectée doit être le propriétaire de ce compte. L'icône pièce dans le rail gauche montre le même solde SSU. Ce n'est pas un lien — utilisez **Credits**.
