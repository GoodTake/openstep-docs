---
title: Utiliser un code
description: Utilisez un code de cours sur /redeem pour débloquer un workspace et du SSU.
sidebar:
  order: 3
---

Ouvrez `/redeem`, ou suivez **Have a course code? Redeem it →** sur la page de connexion. Le titre est **Redeem your course code**.

1. Saisissez un code du type `STEPS-ABCD-EFGH-IJKL` dans **Course code**.
2. La page vérifie d'abord le code. Si vous n'êtes pas connecté, connectez un wallet pour le réclamer.
3. En cas de succès, le workspace correspondant est débloqué et vous recevez le SSU attaché au code.

Vous n'avez pas besoin d'un projet au préalable. Si le code est invalide, déjà utilisé par un autre wallet, ou temporairement indisponible, la page affiche la raison.
