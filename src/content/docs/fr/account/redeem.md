---
title: Utiliser un code
description: Utilisez un code de cours sur /redeem pour débloquer le workspace du cours et le SSU qui l'accompagne.
sidebar:
  order: 3
---

Ouvrez `/redeem`, ou choisissez **+ Redeem a code** dans le menu du compte en bas du rail gauche, ou suivez **Have a course code? Redeem it →** sur la page de connexion. Le titre est **Redeem your course code**.

1. Saisissez un code du type `STEPS-ABCD-EFGH-IJKL` dans **Course code**. Quand la page reconnaît le code, une carte sous **Unlocks** montre le cours et le SSU qu'il ajoute.
2. Si vous n'êtes pas connecté, la page indique **Code checked. Connect a wallet below to claim it.** Sous **Step 2 · Connect your wallet**, choisissez un wallet. Si vous êtes connecté, cliquez sur **Redeem code**.
3. En cas de succès, la page indique **Workspace created**, avec le nom du cours et le SSU qu'il vous donne. Cliquez sur **Open your workspace**.

Le SSU peut arriver un peu après que le workspace est prêt. Cliquez sur **Refresh status** pour vérifier. Votre page [Balance](/fr/account/balance/) l'affiche dès qu'il est arrivé.

Vous n'avez pas besoin d'avoir déjà un agent. Si le code est invalide ou révoqué, déjà utilisé par un autre wallet, ou temporairement indisponible, la page affiche la raison. Si vous faites trop de tentatives, elle vous demande d'attendre une minute. D'autres façons d'obtenir du SSU se trouvent dans [Obtenir du SSU](/fr/start/get-ssu/).
