**Preview** est le côté droit de la page de travail. Il montre votre site tel qu'il est en ce moment, pour que vous puissiez cliquer partout et l'essayer avant que quiconque d'autre le puisse.

1. Cliquez sur **Preview** en haut du côté droit. Pendant que le builder travaille, vous voyez une carte qui indique **Building your The Cozy Coffee Table…**, puis **Opening your The Cozy Coffee Table…**, puis le site.
2. Choisissez une page avec le sélecteur de page, qui démarre sur **Home**. Pour le café, il liste **Home**, **Menu** et **Book a table**.
3. Choisissez **Desktop** ou **Mobile** dans le sélecteur d'appareil pour voir le site dans l'une ou l'autre taille.
4. Utilisez le site comme le ferait un visiteur. Sur **Book a table**, remplissez le formulaire et cliquez sur **Book a table** : le site enregistre la réservation et affiche une confirmation.
5. Cliquez sur **Open** pour voir le site dans son propre onglet de navigateur, ou sur le bouton de rechargement pour recharger la page.

![La page Book a table de The Cozy Coffee Table dans Preview, avec le formulaire de réservation et les horaires d'ouverture.](/images/build/preview-1.webp)

## À savoir

- Preview montre votre brouillon, pas le site en ligne. Les personnes avec qui vous partagez le site ne voient que ce que vous avez publié. Pour leur donner une adresse, [mettez-le en ligne](/fr/build/go-live/).
- Preview utilise des données de développement. La réservation de test que vous venez de faire n'est pas sur le site en ligne, et vous pouvez la voir sous **Data**. Voir [Données du site](/fr/build/data/).
- Après chaque tour, Preview montre la nouvelle version. Pour changer quelque chose, demandez dans le chat.
- Si Preview ne peut pas démarrer, il affiche **Preview failed to start.** ou **Preview timed out. It is taking longer than usual to start.** Cliquez sur **Retry**.
- Pour pointer une partie de la page, utilisez le crayon qui active **Edit mode**. Voir [Décrire ce que vous voulez](/fr/build/describe/).
