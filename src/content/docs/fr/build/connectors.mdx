Un connector permet à votre site de travailler avec l'un de vos comptes sur un autre service : enregistrer les réservations dans une Google Sheet, publier sur Slack, ouvrir une issue GitHub, ou trader sur un exchange. Vous connectez le compte une seule fois. La plateforme garde la clé et fait les appels pour votre site.

## Connectors disponibles

| Service | Ce que votre site peut faire | Comment se connecter |
|---|---|---|
| Google Drive | Lire et modifier les Sheets et Docs que vous choisissez | Connexion |
| Google Calendar | Lire, créer et modifier les événements des agendas que vous choisissez | Votre propre app, puis connexion |
| Google Analytics 4 | Lire les rapports des propriétés que vous choisissez | Votre propre app, puis connexion |
| Slack | Publier dans les canaux publics que vous choisissez | Connexion |
| Lark / Feishu | Lire et modifier les Sheets, Docs et Bases que vous choisissez | Votre propre app, puis connexion |
| HubSpot | Lire et gérer les contacts et les transactions | Votre propre app, puis connexion |
| Mailchimp | Tenir à jour les membres et tags des audiences que vous choisissez | API key |
| LinkedIn | Publier des posts texte avec votre profil | Votre propre app, puis connexion |
| Xero | Lire la comptabilité des organisations que vous choisissez | Votre propre app, puis connexion |
| Zendesk | Lire, créer et répondre aux tickets | Votre propre app, puis connexion |
| GitHub | Lire les issues et pull requests, ouvrir des issues dans les dépôts que vous choisissez | Personal access token |
| Resend | Envoyer les e-mails du site depuis votre propre domaine | API key |

**Votre propre app** : créez une app (un client OAuth) dans les paramètres développeur du service, puis collez son ID et son secret dans le formulaire de connexion.

## Connectors de trading

Les connectors de trading permettent au builder et à votre site de travailler avec votre compte d'exchange : lire les soldes et les positions, passer et clôturer des ordres. Vous connectez votre propre compte d'exchange dans **Plugins & connections** : approuvez sur la page de l'exchange ou avec votre wallet, ou, pour OKX, collez une API key de votre compte dans le formulaire de connexion. Les clés n'entrent jamais dans le chat ou le code.

    { title: 'OpenStep se connecte', text: 'Il garde l\'approbation ou la clé, chiffrée.', highlight: true },
    { title: 'Le builder et le site tradent', text: 'Lire les soldes, passer et clôturer des ordres.' },
  ]}
/>

| Exchange | Comment approuver | Ce qu'il peut faire |
|---|---|---|
| Hyperliquid | Signez une fois avec votre wallet pour approuver une clé de trading. Cette clé ne peut pas retirer de fonds. | Perpétuels : soldes, positions, ordres au marché et à cours limité, take-profit et stop-loss, annulation, clôture |
| OKX | Collez une API key, son secret et sa passphrase depuis votre compte OKX, créés avec Read et Trade seulement. Une clé qui peut retirer est refusée. Choisissez Demo ou Live. | Spot et swaps perpétuels : soldes, positions, ordres, données de marché |
| Binance | Connectez-vous sur Binance et choisissez ce que vous autorisez. Les ordres passent dans un sous-compte Binance séparé que vous alimentez vous-même. Les retraits ne sont jamais autorisés. | Données de marché, soldes, ordres |

:::caution[Les ordres sont réels]
En Preview, votre site trade avec le compte connecté, et dans le chat le builder peut passer un ordre si vous le demandez. Pendant la construction, utilisez un compte démo ou testnet quand l'exchange en propose un.
:::

Quand une connexion affiche **Needs reconnect**, cliquez sur **Reconnect** et approuvez de nouveau.

## Plugins : MCP servers

Les plugins donnent des outils en plus au **builder** pendant qu'il travaille dans le chat, par exemple pour consulter les données d'un service partenaire. La plateforme les ajoute. Le owner de l'agent les active dans **Plugins & connections → MCP servers**. Cette section n'apparaît que si la plateforme en propose.

## En cas de problème

| Vous voyez | Que faire |
|---|---|
| Connections are not available for this agent yet. | Les connectors s'activent agent par agent. Contactez l'équipe OpenStep. |
| The connected account stopped working. Reconnect it to continue. | Cliquez sur **Reconnect** dans Plugins & connections. |
| The app needs more access than the account allowed. | Connectez-vous de nouveau et autorisez l'accès demandé. |
