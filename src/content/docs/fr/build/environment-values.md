---
title: Déployer le backend
description: Déployez le backend du projet depuis Console → Deploy.
sidebar:
  order: 11
---

**Deploy** n'apparaît sous Console → APP que si le projet a un backend.

Ouvrez-le et cliquez sur **Deploy backend (Development)**. En cas de succès, la page affiche le sous-domaine déployé (par exemple **Backend deployed: …**). Les projets sans backend n'affichent pas cet élément.

Preview et le déploiement backend sont distincts : l'interface web peut d'abord apparaître dans **Preview** ; utilisez Deploy quand le backend doit servir des API.
