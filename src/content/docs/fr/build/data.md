---
title: Données de l'app
description: Utilisez la vue Data pour parcourir les tables et les lignes.
sidebar:
  order: 9
---

Quand le projet inclut une app web, le sélecteur à droite comprend **Data**. Il liste les tables utilisées par l'app. Vous pouvez parcourir les lignes, en ajouter et les modifier.

Traitez Data comme les données métier que votre app utilise — pas un produit base de données séparé à provisionner. Les tables apparaissent au fil de la construction. Après un tour qui crée des tables, ouvrez **Data** pour les voir.

Les projets sans app web n'affichent pas le sélecteur Data.
