---
title: Choisir un modèle
description: Choisissez un modèle dans Run configuration. Le changer ne démarre pas un tour.
sidebar:
  order: 5
---

Le sélecteur de modèle est dans **Run configuration**, dans la barre du haut de l'éditeur (et à côté de **Run mode** sur `/projects/new`).

Changer le modèle ne démarre pas un tour. Le prochain message que vous envoyez utilise le modèle sélectionné.

Si un modèle n'est pas disponible, le sélecteur l'affiche comme désactivé. Choisissez-en un autre.
