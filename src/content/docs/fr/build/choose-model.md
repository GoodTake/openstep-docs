Le builder s'appuie sur un modèle d'IA. Par défaut, **Auto** choisit le meilleur pour chaque demande, et pour la plupart des sites, cela suffit. Si vous préférez choisir, vous pouvez sélectionner un modèle nommé dans le même menu que celui du mode.

1. Cliquez sur la puce en bas de la zone de chat, par exemple **Auto · Build**. Sur **New agent** et **Home**, le contrôle de modèle **Auto** se trouve à côté de la bascule **Build** / **Brainstorm**.
2. Sous **Select model** (**Choose how STEPS routes this turn**), laissez **Auto** (**Best model for each request**) sélectionné, ou regardez sous **Choose model** (**Pick a model for this run**) et cliquez sur un modèle dans la liste.
3. Envoyez votre message. Il s'exécute avec le modèle qu'affiche maintenant la puce.

![La puce de la zone de chat ouverte : Select model avec Auto coché, une courte liste Choose model en dessous, et Run mode en bas.](/images/build/choose-model-1.webp)

Changer de modèle ne lance rien par soi-même. Cela change seulement la façon dont votre prochain message est traité.

## À savoir

- La liste sous **Choose model** évolue avec le temps ; ce guide ne nomme donc aucun modèle. Le menu montre toujours ce qui est disponible maintenant.
- La puce est grisée pendant que le builder travaille. Changez de modèle entre deux messages.
- Si la puce indique **Loading models**, patientez un instant. Si elle indique **Models unavailable**, cliquez dessus pour réessayer.
- Le même menu contient le mode. Voir [Build et Brainstorm](/fr/build/modes/).
