---
title: Parcourir le code
description: Ouvrez Code dans Console pour inspecter les fichiers du projet.
sidebar:
  order: 11
---

Dans la barre du haut du projet, ouvrez **Console**. Sous le groupe APP, cliquez sur **Code**. Vous pouvez parcourir les fichiers et les ouvrir pour les lire.

C'est pour vérifier ce que l'IA vient de changer. Vous n'avez pas à éditer les fichiers à la main pour terminer une construction. Les changements du quotidien passent toujours par le chat à gauche.

Console a aussi **Assets** pour les images et fichiers enregistrés dans le projet.
