Vous n'avez jamais besoin de lire du code pour construire un site, mais vous pouvez le faire. **Code** montre les fichiers que le builder a écrits, pour que vous puissiez vérifier ce qu'il a changé.

1. Cliquez sur **Console** dans l'en-tête, puis sur **Code**. Il montre les fichiers de l'App choisie dans le sélecteur d'App de l'en-tête.
2. Ouvrez un dossier sous **FILES** et cliquez sur un fichier. Pour le café, les dossiers comprennent `migrations`, `public`, `scripts` et `src`, et `src/App.tsx` liste les pages du site.
3. Lisez le fichier dans l'éditeur à droite. Il s'ouvre dans un onglet, et le chemin du fichier ouvert est affiché en haut.
4. Cliquez sur **Back to Console** pour revenir aux autres sections de la Console.

![Console → Code pour The Cozy Coffee Table : l'arborescence FILES à gauche et src/App.tsx ouvert dans un éditeur en lecture seule.](/images/build/code-1.webp)

La barre d'outils au-dessus de l'éditeur contient les boutons **Files**, **Quick Open**, **Search**, **Refresh**, **Copy path**, **Copy content**, **Download file** et **Copy link**.

## À savoir

- Code est en lecture seule. Pour changer le site, demandez dans le chat à gauche. Voir [Décrire ce que vous voulez](/fr/build/describe/).
- **Copy path** est pratique quand vous voulez désigner un fichier au builder : collez le chemin dans votre message.
- **Refresh** recharge la liste des fichiers, par exemple après que le builder en a ajouté.
- Code montre le brouillon que montre Preview, pas ce qui est en ligne.
