Les sites web sont construits par l'agent **Web builder** : vous décrivez le site, et il le construit. Cette section suit un petit site, du premier message à l'adresse en ligne : un café appelé The Cozy Coffee Table, avec un menu, des horaires d'ouverture et un formulaire pour réserver une table.

1. Cliquez sur **+ New agent** dans le rail gauche. **New agent** s'ouvre avec **Based on** réglé sur **Web builder** et **Build** sélectionné.
2. Décrivez le site dans la zone qui indique **Describe an app, a learning experience, or your next idea…**. Pour le café, nous avons écrit : *A website for a small coffee shop: the menu, opening hours, and a form to book a table.*
3. Laissez **Build** sélectionné et le modèle sur **Auto**. La ligne sous la zone indique **Build changes it directly.**
4. Cliquez sur **Start building →**.

![La page New agent avec Web builder choisi, la demande du café saisie et Build sélectionné.](/images/build/start-website-1.webp)

L'agent est créé et sa page de travail s'ouvre avec votre message déjà envoyé. Le builder nomme l'agent d'après votre demande ; le nôtre est devenu The Cozy Coffee Table. Comme vous avez choisi **Build**, il démarre aussitôt : pas de questions, pas de plan à approuver.

Pendant qu'il travaille, la carte de Preview à droite passe par **Thinking**, **Planning**, **Writing code**, **Preview & test** et **Done**. Quand la construction est terminée, le dernier message du builder liste ce qui fonctionne désormais. Pour le café, c'était une page d'accueil, une page de menu et une page **Book a table** dont le formulaire enregistre les réservations. La première construction de ce site a pris environ 15 minutes.

## À savoir

- La construction dépense du SSU. Si votre solde est vide, [obtenez d'abord du SSU](/fr/start/get-ssu/).
- Vous pouvez arriver sur **New agent** de trois façons : **+ New agent** dans le rail gauche, **What would you like to build?** sur **Home**, ou **Use this agent →** sur la carte **Website or app** du Marketplace. Dans le Marketplace, Web builder s'appelle **Website or app** ; sur **New agent**, il s'appelle **Web builder**.
- Le builder choisit lui-même un menu, des prix et des horaires d'ouverture. Ce sont des valeurs provisoires : demandez-lui de les changer quand vous voulez.
- Vous ne savez pas encore exactement ce que vous voulez ? Choisissez **Brainstorm** plutôt que **Build**, et le builder commence par poser des questions. Voir [Build et Brainstorm](/fr/build/modes/).
- Des conseils pour le premier message se trouvent dans [Décrire ce que vous voulez](/fr/build/describe/).
