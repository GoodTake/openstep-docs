Vous démarrez un agent sur **New agent** : choisissez sur quoi il repose, dites-lui ce que vous avez en tête, puis lancez-le. L'agent est créé et sa page de travail s'ouvre avec votre message déjà envoyé.

1. Ouvrez **New agent**. Il y a trois façons d'y arriver, et elles mènent toutes à la même zone :
   - Cliquez sur **+ New agent** dans le rail gauche.
   - Utilisez **What would you like to build?** sur **Home**.
   - Cliquez sur **Use this agent →** sur une carte du **Marketplace**. **New agent** s'ouvre avec ce produit déjà choisi.
2. Sous **Based on**, vérifiez sur quoi repose l'agent. Il affiche **Web builder** par défaut, qui construit un site web ou une app à partir de votre description. Pour utiliser plutôt un agent prêt à l'emploi, ouvrez le menu **Based on** ou cliquez sur une carte sous **A great place to start**, comme **Health & fitness**.
3. Décrivez ce que vous voulez dans la zone qui indique **Describe an app, a learning experience, or your next idea…**. Par exemple : *I want to get stronger. I can train 3 days a week at the gym, about 45 minutes each time.*
4. Choisissez **Build** ou **Brainstorm**. La page choisit une valeur par défaut selon l'agent : **Web builder** démarre en **Build**, et **Health & fitness** démarre en **Brainstorm**. La ligne sous la zone indique ce que fait le mode. Voir [Build et Brainstorm](/fr/build/modes/).
5. Laissez le modèle sur **Auto**, ou choisissez-en un autre. Voir [Choisir un modèle](/fr/build/choose-model/).
6. Cliquez sur le bouton de démarrage. Il indique **Start brainstorming →** en **Brainstorm** et **Start building →** en **Build**.

![La page New agent avec Health & fitness choisi, un premier message saisi et Brainstorm sélectionné.](/images/start/create-agent-1.webp)

## À savoir

- Le builder donne un nom au nouvel agent. Vous le retrouverez plus tard dans **My agents**, ou sous **RECENT AGENTS** dans le rail gauche.
- La construction dépense du SSU. Si votre solde est vide, [obtenez d'abord du SSU](/fr/start/get-ssu/).
- Dans le Marketplace, l'agent par défaut est listé sous le nom **Website or app**. Sur **New agent**, le même agent s'appelle **Web builder**.
