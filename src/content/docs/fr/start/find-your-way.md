Après la connexion, vous arrivez sur **Home**. Le rail gauche est présent sur chaque page : vous pouvez donc aller partout depuis celui-ci.

![Home avec le rail gauche à gauche : New agent, Home, Marketplace, My agents, Campus Earth, Members, Settings, les agents récents, et votre solde en bas.](/images/start/find-your-way-1.webp)

## Le rail gauche

De haut en bas :

- **Workspace switcher** (**Personal** au départ) : le workspace dans lequel vous travaillez. Vos agents appartiennent à un workspace.
- **+ New agent** : ouvre **New agent**, où vous démarrez un agent. Voir [Créer votre premier agent](/fr/start/create-agent/).
- **Home** : votre page de départ (voir ci-dessous).
- **Marketplace** : les agents prêts à l'emploi à partir desquels vous pouvez démarrer. Voir [Choisir un agent dans le Marketplace](/fr/agent/pick-agent/).
- **My agents** : tout ce que vous possédez ou sur quoi vous collaborez, l'activité la plus récente en premier. Filtrez par statut, comme **Building** ou **Live**. Voir [Gérer vos agents](/fr/agent/manage-agents/).
- **Campus Earth** : les expériences d'apprentissage que vous avez rejointes, par exemple un cours auquel vous avez été invité. Vos propres agents restent dans **My agents**.
- **Members** (sous **WORKSPACE**) : les personnes qui collaborent dans ce workspace, et **Invite member**. Voir [Travailler à plusieurs](/fr/agent/work-with-others/).
- **Settings** (sous **WORKSPACE**) : le nom du workspace, votre utilisation et votre solde, les appareils autorisés pour la CLI OpenStep, et le transfert de propriété.
- **RECENT AGENTS** : vos derniers agents, à un clic depuis le rail gauche.
- **Balance**, en bas : votre solde de SSU. Cliquez dessus pour ouvrir la page Balance. Voir [Vérifier votre solde](/fr/account/balance/).
- Votre wallet, sous **Balance** : ouvre le menu du compte.

## Home

**Home** affiche :

- **Welcome back**, avec **Total agents**, **Building** et **Needs attention**, votre **Platform balance** en SSU avec un bouton **+ Top up**, et **Wallet assets**.
- **What would you like to build?**, la même zone que sur **New agent**. Décrivez ce que vous voulez, choisissez **Build** ou **Brainstorm**, puis démarrez. Voir [Créer votre premier agent](/fr/start/create-agent/).
- **Recently edited**, une carte pour chacun de vos derniers agents, avec un badge **Live** ou **Draft**. **View all agents →** ouvre **My agents**.

## Le menu du compte

Cliquez sur votre wallet en bas du rail gauche. Le menu comprend :

- **Balance** : la même page que **Balance** dans le rail gauche.
- **Purchase SSU** : acheter du SSU. Voir [Obtenir du SSU](/fr/start/get-ssu/).
- **+ Redeem a code** : utiliser un code de cours. Voir [Utiliser un code](/fr/account/redeem/).
- **Disconnect** : se déconnecter.

## À savoir

- Sur la page de travail d'un agent, le rail gauche se réduit à des icônes pour laisser plus de place à la conversation et à l'app.
- Tout ce que vous créez se trouve dans **My agents**. Les cours que vous rejoignez se trouvent dans **Campus Earth**.
