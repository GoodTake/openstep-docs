Quand le projet s'ouvre, le chat est à gauche. La droite est en général **Preview** si le projet inclut une app web.

Si vous avez déjà écrit une description à la création, le premier tour démarre. Sinon, tapez ce que vous voulez dans le champ et appuyez sur Entrée.

Au premier tour, dites :

- À qui c'est destiné, en une phrase
- Ce qu'ils voient d'abord
- Les écrans ou actions indispensables (par exemple « claim tokens » ou « check in »)

Sous la bulle de l'assistant, une ligne d'état apparaît, par exemple **Thinking**, **Planning**, ou **Building**. Preview affiche l'app dès qu'elle peut s'ouvrir.

En **Brainstorm**, l'IA pose des questions ou propose un plan et ne change pas le code. Quand le plan convient, cliquez sur **Start building**. Voir [Confirmer le plan](/fr/chat/confirm-plan/).
