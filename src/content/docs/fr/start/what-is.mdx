OpenStep est un builder full-stack IA. Sur [builder.openstep.academy](https://builder.openstep.academy), vous décrivez le système voulu dans le chat, et la plateforme le construit dans un environnement isolé — prêt à prévisualiser et à publier.

Vous n'avez pas besoin d'un serveur ou d'un dépôt git au départ. Ouvrez le produit, connectez-vous avec un wallet, créez un projet, et dites ce que vous voulez.

Ce site explique **comment utiliser le builder OpenStep**. Ce que votre app publiée peut faire (encaisser, envoyer un e-mail, stocker des données) est un aperçu court sous Créer votre app — pas un catalogue d'API.
