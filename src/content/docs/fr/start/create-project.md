title: Créer votre premier projet
description: Décrivez le système voulu sur /projects/new et créez un projet.

Après la connexion, choisissez **New project** dans le rail gauche, ou ouvrez `/projects/new`.

Le titre est **What do you want to create?** Le sous-titre est **Describe your idea, or start from an example.**

1. Décrivez le système dans le champ (vous pouvez aussi le laisser vide et parler plus tard).
2. Vous pouvez choisir **Build** ou **Brainstorm** avec le contrôle segmenté **Run mode** (Build par défaut). **Brainstorm** pose des questions et n'écrit pas de code ; **Build** écrit du code dans le projet. Voir [Build et Brainstorm](/fr/chat/modes/).
3. Vous pouvez changer le modèle dans le sélecteur.
4. Cliquez sur la flèche vers le haut (nom accessible **Create project**) ou appuyez sur Entrée (Maj+Entrée pour une nouvelle ligne).

Les puces d'exemple remplissent une consigne, par exemple **Habit tracker web app**, **Launch a token**, et **Token with a claim page**.

En cas de succès, l'éditeur du projet s'ouvre (`/projects/:id`). Si vous avez saisi une description, elle est envoyée comme premier tour de chat.
