**Run mode** est **Build** ou **Brainstorm**.

- **Build** — l'IA écrit et modifie le code du projet. Utilisez-le pour une app qui fonctionne.
- **Brainstorm** — l'IA pose des questions et propose un plan. Elle n'écrit pas de code. Utilisez-le tant que l'idée n'est pas figée.

**Où changer**

- Sur `/projects/new`, un contrôle segmenté **Run mode** est à côté du sélecteur de modèle.
- Dans l'éditeur, ouvrez **Run configuration** (barre du haut) et changez **Run mode** dans le menu. Il n'y a pas de contrôle segmenté dans l'éditeur.

Vous pouvez changer de mode entre les tours. Vous ne pouvez pas le changer pendant un tour.

Après qu'un Brainstorm a produit un plan, confirmez avec **Start building**. Voir [Confirmer le plan](/fr/chat/confirm-plan/).
