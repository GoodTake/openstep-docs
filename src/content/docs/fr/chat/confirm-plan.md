title: Confirmer le plan
description: Après Brainstorm, Start building écrit le code. Keep refining reste en Brainstorm.
sidebar:
  order: 3
---

Quand un tour Brainstorm se termine avec un plan, deux actions apparaissent sous le dernier message de l'assistant :

- **Start building** — le tour suivant s'exécute en **Build** et écrit le code à partir du plan.
- **or keep refining** — rester en **Brainstorm** et continuer à parler.

Cette confirmation n'apparaît qu'après Brainstorm, pas après un tour Build.

Si vous ignorez la confirmation et envoyez un nouveau message tout en restant en Brainstorm, l'IA continue de poser des questions et n'écrit pas de code.
