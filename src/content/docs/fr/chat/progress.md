Pendant un tour, une ligne d'état apparaît sous la bulle de l'assistant. Libellés typiques :

- **Preparing** — préparation de l'environnement
- **Waiting for a free build slot** — la file est occupée
- **Thinking** — le modèle travaille
- **Planning** — écriture ou mise à jour d'un plan
- **Building** — modification du code
- **Done** — le tour est terminé
- **Cancelled** — vous avez arrêté le tour

Vous ne pouvez pas envoyer un autre message tant que le tour en cours n'est pas fini ou annulé. Utilisez **Stop** dans le champ pour annuler.

Si la file est occupée, attendez. Vous n'avez pas besoin de rafraîchir ; la page se met à jour toute seule.
