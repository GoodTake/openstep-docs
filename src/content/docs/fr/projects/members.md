---
title: Inviter des membres
description: Ajoutez des personnes au workspace par adresse de wallet sur la page Members.
sidebar:
  order: 2
---

Cliquez sur **Members** dans le rail gauche pour ouvrir `/projects/members`. Le titre est **Manage who can access this workspace**.

Si vous pouvez gérer les membres, l'action en haut à droite est **Add wallet**. Le titre de la boîte de dialogue est **Add workspace member**. Saisissez une **Wallet address** (`0x...`) et cliquez sur **Add member**. Le texte indique que le wallet ajouté peut voir tous les projets de ce workspace.

Il n'y a pas de page d'invitation par lien. Ajoutez l'adresse de wallet de l'autre personne.
