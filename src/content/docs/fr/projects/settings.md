**Settings** dans le rail gauche ouvre `/projects/settings` (sous un projet, c'est `/projects/:id/settings` — les mêmes réglages de workspace).

Ici vous pouvez :

- Renommer le workspace (les workspaces personnels ne peuvent pas être renommés)
- **Transfer ownership** vers un autre membre déjà dans le workspace
- **Delete workspace** (confirmez le nom comme demandé)

La publication, les domaines et le code au niveau projet ne sont pas sur cette page. Utilisez la **Console** de ce projet.
