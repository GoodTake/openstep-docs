- La construction se fait dans un environnement isolé fourni par la plateforme. Vous n'avez pas besoin de votre propre hôte pour commencer.
- Si une conversation devient trop longue, démarrez un nouveau chat. Le projet reste.
- Vous ne pouvez pas publier tant que l'IA est encore **Building**. Attendez la fin du tour.
- Pour un domaine personnalisé, utilisez la cible DNS affichée sur le panneau **Domains** de ce projet à ce moment.
- Ce site documente le produit builder. Ne traitez pas les spécifications d'ingénierie internes ou les notes de déploiement comme de la documentation utilisateur.
