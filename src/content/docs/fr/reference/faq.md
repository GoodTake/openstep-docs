**Pourquoi dois-je signer deux fois ?**  
D'abord connectez le wallet, puis signez une demande de connexion. La deuxième étape n'est pas un transfert. La page indique **no transaction, no gas**.

**Pourquoi Brainstorm n'a-t-il pas changé mon app ?**  
C'est voulu. Brainstorm ne fait que discuter. Cliquez sur **Start building** pour écrire du code.

**Quelle est la différence entre Preview et Publish ?**  
Preview est le brouillon que vous éditez. Publish pousse une version vers une URL que d'autres peuvent ouvrir.

**Puis-je encaisser dans une autre monnaie ?**  
Non. Le paiement in-app est en SSU uniquement.
