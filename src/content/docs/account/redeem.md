---
title: Redeem a code
description: Redeem a course code at /redeem to unlock a workspace and SSU.
sidebar:
  order: 3
---

Open `/redeem`, or follow **Have a course code? Redeem it →** on the sign-in page. The heading is **Redeem your course code**.

1. Enter a code like `STEPS-ABCD-EFGH-IJKL` in **Course code**.
2. The page checks the code first. If you are not signed in, connect a wallet to claim it.
3. On success, the matching workspace is unlocked and you receive the SSU attached to the code.

You do not need a project first. If the code is invalid, already used by another wallet, or temporarily unavailable, the page shows the reason.
