OpenStep 把一段對話變成一個能運作的 App。你建立一個 Agent，告訴它你需要什麼，它就會建出一個或多個 App，讓你在 [builder.openstep.academy](https://builder.openstep.academy) 預覽與發布。

## 各部分如何組合

  <span class="arrow" aria-hidden="true">→</span>
  <div class="node accent"><b>Agent</b><small>對話 · 計畫 · 建造</small></div>
  <span class="arrow" aria-hidden="true">→</span>
  <div class="stack">

    <div class="node"><b>App</b><small>需要幾個就有幾個</small></div>
  </div>
  <span class="arrow" aria-hidden="true">→</span>
  <div class="node"><b>上線連結</b><small>Publish 之後</small></div>
</div>

一個 Agent 會把你的對話與它的建造內容放在同一個地方，而且可以替你建出好幾個 App。**Publish** 會把它們一起上線。

## 你會看到的詞彙

| 詞彙 | 意思 |
| --- | --- |
| **Agent** | 你建立並持續使用的東西：對話、它的建造內容，以及它的 App。 |
| **App** | Agent 裡的一個網站，有自己的預覽、程式碼、資料與上線連結。 |
| **Marketplace** | 可以直接拿來起步的現成 Agent 清單。 |
| **Brainstorm** / **Build** | 兩種工作方式。**Brainstorm** 先提問並擬出計畫；**Build** 直接修改你的 App。 |
| **Publish** | 讓 Agent 的每個 App 一起上線。 |
| **SSU** | 建造與 App 功能所花費的額度。見 [取得 SSU](/zh-tw/start/get-ssu/)。 |

## 你送出第一則訊息之後

<ol class="flow not-content">
  <li>Agent 會問幾個問題</li>
  <li>你核准它的計畫</li>
  <li>它一個任務接一個任務地建造</li>
  <li>你在 **Preview** 試用</li>
  <li>你 **Publish** 並分享</li>
</ol>

這是 **Brainstorm** 的流程。在 **Build** 模式下，沒有問題，也沒有需要核准的計畫：Agent 會直接開始修改你的 App。
