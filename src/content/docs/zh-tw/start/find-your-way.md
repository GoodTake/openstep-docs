登入後你會進入 **Home**。左側欄在每個頁面都有，所以你可以從那裡前往任何地方。

![左邊是左側欄的 Home：New agent、Home、Marketplace、My agents、Campus Earth、Members、Settings、最近的 Agent，以及底部的餘額。](/images/start/find-your-way-1.webp)

## 左側欄

由上到下：

- **Workspace switcher**（工作區切換器，一開始是 **Personal**）：你目前所在的工作區。你的 Agent 屬於某個工作區。
- **+ New agent**：開啟 **New agent**，在那裡建立 Agent。見 [建立你的第一個 Agent](/zh-tw/start/create-agent/)。
- **Home**：你的起始頁（見下文）。
- **Marketplace**：可以直接拿來起步的現成 Agent。見 [從 Marketplace 挑選 Agent](/zh-tw/agent/pick-agent/)。
- **My agents**：你擁有或協作的所有 Agent，最近有動作的排在最前面。可以依狀態篩選，例如 **Building** 或 **Live**。見 [管理你的 Agent](/zh-tw/agent/manage-agents/)。
- **Campus Earth**：你加入的學習體驗，例如受邀參加的課程。你自己的 Agent 仍在 **My agents**。
- **Members**（在 **WORKSPACE** 底下）：在這個工作區協作的人，以及 **Invite member**。見 [與他人協作](/zh-tw/agent/work-with-others/)。
- **Settings**（在 **WORKSPACE** 底下）：工作區名稱、你的用量與餘額、已授權使用 OpenStep CLI 的裝置，以及所有權轉移。
- **RECENT AGENTS**：你最近的 Agent，從左側欄點一下就能進入。
- 底部的 **Balance**：你的 SSU 餘額。點選它即可開啟餘額頁。見 [查看餘額](/zh-tw/account/balance/)。
- **Balance** 下方是你的錢包：點選它會開啟帳號選單。

## Home

**Home** 會顯示：

- **Welcome back**，以及 **Total agents**、**Building** 和 **Needs attention**、以 SSU 計的 **Platform balance**（旁邊有 **+ Top up** 按鈕），還有 **Wallet assets**。
- **What would you like to build?**，與 **New agent** 上是同一個輸入框。描述你想要的東西，選擇 **Build** 或 **Brainstorm**，然後開始。見 [建立你的第一個 Agent](/zh-tw/start/create-agent/)。
- **Recently edited**，為你最近的每個 Agent 各放一張卡片，帶有 **Live** 或 **Draft** 標記。**View all agents →** 會開啟 **My agents**。

## 帳號選單

點選左側欄底部的錢包。選單包含：

- **Balance**：與左側欄的 **Balance** 是同一個頁面。
- **Purchase SSU**：購買 SSU。見 [取得 SSU](/zh-tw/start/get-ssu/)。
- **+ Redeem a code**：使用課程代碼。見 [兌換代碼](/zh-tw/account/redeem/)。
- **Disconnect**：登出。

## 注意事項

- 在 Agent 的工作頁，左側欄會收合成圖示，讓對話與 App 有更多空間。
- 你建立的所有東西都在 **My agents**。你加入的課程則在 **Campus Earth**。

下一步：[取得 SSU](/zh-tw/start/get-ssu/)。
