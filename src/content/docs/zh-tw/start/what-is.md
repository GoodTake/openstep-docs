OpenStep 是 AI 全端建造工具。在 [builder.openstep.academy](https://builder.openstep.academy) 用對話描述你要的系統，平台在隔離環境裡把它建出來——可預覽、可發布。

你不必先自備伺服器或 git 倉庫。打開產品、用錢包登入、建立專案，然後說你要什麼。

本站說明 **如何使用 OpenStep builder**。你發布的應用能做什麼（收款、寄信、存資料）在「打造你的應用」裡有短覽，不是 API 目錄。
