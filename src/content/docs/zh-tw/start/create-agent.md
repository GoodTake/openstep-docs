---
title: 建立第一個專案
description: 在 /projects/new 描述你要的系統並建立專案。
sidebar:
  order: 5
---

登入後，在左側欄選 **New project**，或打開 `/projects/new`。

標題是 **What do you want to create?** 副標是 **Describe your idea, or start from an example.**

1. 在輸入框描述系統（也可以先留空，稍後再聊）。
2. 可用分段開關 **Run mode** 選 **Build** 或 **Brainstorm**（預設是 Build）。**Brainstorm** 只提問、不寫程式；**Build** 會在專案裡寫程式。見 [Build 與 Brainstorm](/zh-tw/build/modes/)。
3. 可在模型選單改模型。
4. 點向上箭頭（無障礙名稱 **Create project**）或按 Enter（Shift+Enter 換行）。

範例晶片會填入提示，例如 **Habit tracker web app**、**Launch a token**、**Token with a claim page**。

成功後打開專案編輯器（`/projects/:id`）。若建立時已寫描述，會作為第一輪對話送出。
