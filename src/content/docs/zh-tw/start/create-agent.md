你在 **New agent** 建立 Agent：選擇它以什麼為基礎、告訴它你的想法，然後開始。Agent 建立後，它的工作頁會開啟，而你的訊息已經送出。

1. 開啟 **New agent**。有三種進入方式，最後都會到同一個輸入框：
   - 點選左側欄的 **+ New agent**。
   - 使用 **Home** 上的 **What would you like to build?**。
   - 點選 **Marketplace** 中某張卡片上的 **Use this agent →**。**New agent** 開啟時，已經選好該產品。
2. 在 **Based on** 底下，確認 Agent 以什麼為基礎。預設是 **Web builder**，它會依你的描述建立網站或 App。如果想改用現成的 Agent，請開啟 **Based on** 選單，或點選 **A great place to start** 底下的卡片，例如 **Health & fitness**。
3. 在寫著 **Describe an app, a learning experience, or your next idea…** 的輸入框裡，描述你想要的東西。例如：*I want to get stronger. I can train 3 days a week at the gym, about 45 minutes each time.*
4. 選擇 **Build** 或 **Brainstorm**。頁面會依你選的 Agent 挑一個預設：**Web builder** 從 **Build** 開始，**Health & fitness** 從 **Brainstorm** 開始。輸入框下方那一行會說明這個模式的作用。見 [Build 與 Brainstorm](/zh-tw/build/modes/)。
5. 模型維持 **Auto**，或另選一個。見 [選擇模型](/zh-tw/build/choose-model/)。
6. 點選開始按鈕。在 **Brainstorm** 下顯示 **Start brainstorming →**，在 **Build** 下顯示 **Start building →**。

![New agent 頁面，已選好 Health & fitness、輸入了第一則訊息，並選了 Brainstorm。](/images/start/create-agent-1.webp)

## 注意事項

- builder 會替新的 Agent 取名。之後你可以在 **My agents** 或左側欄的 **RECENT AGENTS** 底下找到它。
- 建造會花費 SSU。如果你的餘額是空的，請先[取得一些 SSU](/zh-tw/start/get-ssu/)。
- 在 Marketplace 裡，預設的 Agent 列為 **Website or app**。在 **New agent** 上，同一個 Agent 叫做 **Web builder**。
