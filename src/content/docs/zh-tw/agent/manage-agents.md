你的 Agent 都列在 **My agents**，每個 Agent 在 Console 中有自己的設定。放著這些 Agent 的工作區也有它自己的設定。

## My agents

點選左側欄的 **My agents**。頁面寫著「Everything you own or collaborate on, newest activity first.」，右上角有 **+ New agent**。

1. 用分頁篩選清單：**All**、**Needs your answer**、**Building**、**Ready to publish**、**Live** 和 **Draft**。要依名稱尋找，請在 **Search agents…** 輸入。
2. 閱讀卡片。每張卡片都顯示狀態標記（**Building**、**Live**、**Draft** 或 **Ready to publish**）、Agent 的名稱、一行說明它現在在做什麼（例如 **Planning**、**Working** 或 **Unpublished changes**）、它所依據的 Agent，以及上次活動的時間。
3. 點選卡片，開啟 Agent 的工作頁。

   ![My agents 頁面，有篩選分頁和一格格的 Agent 卡片，其中 Three Day Strength 標示為 Building。](/images/agent/manage-agents-1.webp)

別人與你分享的 Agent 也會出現在這裡，並附上你的存取等級。你加入的學習體驗則留在 **Campus Earth**。

## 變更單一 Agent

開啟 Agent，點選標題列的 **Console**，再點選 **Settings**。

- 重新命名。在 **Display** 底下，變更 **Agent name** 並點選 **Save changes**。你也可以在這裡挑選 **Avatar** 顏色和 **Card image**，用 **Upload image** 或 **Generate**。**Language** 和 **Tone** 會改變 Agent 寫作與說話的方式，並在它下次建造時生效。擁有者和編輯者都可以重新命名。
- **Duplicate agent**。在 **Ownership and workspace** 底下，點選 **Duplicate agent**。你會得到一個新的 Agent，帶有每個 App 的程式碼副本，可以任意修改而不動到原本的 Agent。資料、值和機密會留在原本的 Agent。按鈕旁邊的框會建議`<agent name> (copy)`；如果想自己取名，請在那裡輸入其他名稱。
- **Move to another workspace**。開啟寫著 **Choose a workspace** 的選單，挑選一個，點選 **Move**，再用 **Move agent** 確認。它的 App 和資料會跟著過去，該工作區的成員可以查看它。它的協作者會失去在它上面的角色，尚未使用的邀請連結也會失效。
- **Transfer ownership**。開啟寫著 **Choose a collaborator** 的選單，挑選那個人，點選 **Transfer ownership**，再用 **Transfer** 確認。你仍留在這個 Agent 上，成為編輯者，而且只有新的擁有者能發布它、變更誰可以開啟它或刪除它。Agent 要先有協作者，你才能轉移它。見 [與他人協作](/zh-tw/agent/work-with-others/)。
- **Delete agent**。在底部的 **Danger zone** 底下，點選 **Delete agent**。**Delete agent permanently** 對話框會說明，這會移除 Agent、它的檔案、它的對話、每個 App 及其資料，而且無法復原。輸入 Agent 的名稱確認，再點選 **Delete agent**。

只有擁有者能複製、移動、轉移或刪除 Agent。**Access** 和協作者清單在同一頁，也只限擁有者使用。見 [發布與分享](/zh-tw/agent/publish-and-share/)。

## 工作區設定

點選左側欄 **WORKSPACE** 底下的 **Settings**。頁面寫著「Manage the workspace that holds your agents.」你也可以從側欄頂部的工作區選單，在 **Workspace settings** 底下進入。

- **GENERAL** 有工作區的 **Name** 和 **Slug**。在團隊工作區，擁有者可以變更名稱並點選 **Save**。個人工作區的名稱是固定的。
- **Usage & balance** 顯示你以 SSU 計的 **Available balance**，以及這個工作區中 **Your agents** 的數量。
- **CLI ACCESS** 列出你已授權、透過 openstep 命令列以你的身分操作的裝置，每個都有 **Revoke**。見 [安裝與登入](/zh-tw/cli/install/)。
- **TRANSFER OWNERSHIP** 把團隊工作區交給另一位活躍的成員：選擇 **New owner**，點選 **Transfer ownership**，再用 **Transfer** 確認。
- **DANGER ZONE** 只在團隊工作區才有。擁有者可以 **Delete workspace**，它會永久刪除工作區和其中的每個 Agent，需先輸入工作區名稱確認。其他成員看到的則是 **Leave workspace**。

左側欄的 **Members** 會列出工作區中的人。見 [與他人協作](/zh-tw/agent/work-with-others/)。

## 注意事項

- 每個 Agent 各自保有協作者、存取與發布的設定。工作區頁面不會變更它們。
- Agent 還在設定中時不能刪除。請等設定完成。
- 刪除工作區會刪除其中的每個 Agent，所以請先把想保留的 Agent 移出去。

這就是使用現成 Agent 的完整流程。若要改為建立網站，請從 [建立網站](/zh-tw/build/start-website/) 開始。
