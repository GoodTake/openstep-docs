Marketplace 列出現成的 Agent。每一個都是為某一類工作而做：它會問你需要什麼、擬出計畫，然後替你建造 App。你挑一個、說出你的想法，就會得到屬於你自己的 Agent。這一節的每一頁都沿用同一個範例 **Health & fitness**，它後來成了一個名為 Three Day Strength 的 Agent。

1. 點選左側欄的 **Marketplace**。這個頁面叫做 **Agent marketplace**：「Choose a product to create your own agent. Continue existing work from My agents.」
2. 瀏覽卡片。**All agents** 會顯示全部，**By OpenStep** 則顯示 OpenStep 製作的。要找特定的 Agent，請在 **Search agents…** 輸入。每張卡片都有圖片、名稱與類別、一行說明它會建造什麼，以及 **Use this agent →**。**Health & fitness** 這張卡片寫著：「Training plan, workout log, weight and measurements.」

   ![Agent marketplace 頁面，有一格格的 Agent 卡片，其中包括 Health & fitness 與它的 Use this agent 按鈕。](/images/agent/pick-agent-1.webp)

3. 點選 **Health & fitness** 上的 **Use this agent →**。**New agent** 會開啟，並已在 **Based on** 底下選好該 Agent。
4. 在寫著 **Describe an app, a learning experience, or your next idea…** 的輸入框裡，寫下你的第一則訊息。你在這裡說得越多，Agent 需要問的問題就越少。例如：*I want to get stronger. I can train 3 days a week at the gym, about 45 minutes each time.*
5. 模式維持在 **Brainstorm**（**Health & fitness** 開始時的模式），模型維持 **Auto**。點選 **Start brainstorming →**。

   ![New agent 頁面，已選好 Health & fitness、輸入了第一則訊息，並選了 Brainstorm。](/images/start/create-agent-1.webp)

Agent 建立完成後，builder 會替它取名，這裡是 Three Day Strength。它的工作頁會立刻開啟，你的訊息已經送出。對話在左邊，帶有 **Preview** 和 **Data** 的 App 檢視區在右邊。Agent 開始閱讀你的訊息，最初的問題幾分鐘後就會送達。

## 注意事項

- Marketplace 上的每張卡片就是一個產品。當你開始使用它，你就會得到屬於你自己的 Agent，而你做的任何事都不會改變別人的 Agent。
- 一個 Agent 可以有一個或多個 App。Health & fitness Agent 建造一個。
- 在 **Brainstorm**，Agent 會先提問、擬出計畫，再一個任務接一個任務地建造。在 **Build**，它則直接修改。見 [Build 與 Brainstorm](/zh-tw/build/modes/)。
- 如果想建立網站，而不是使用現成的 Agent，見 [建立網站](/zh-tw/build/start-website/)。
- 你開始的每個 Agent 都列在 **My agents**，也列在左側欄的 **RECENT AGENTS** 底下。
- Agent 的工作會花費 SSU。如果你的餘額偏低，請先[取得一些 SSU](/zh-tw/start/get-ssu/)。
