點選左側欄底部的 **Balance** 即可開啟 Balance 頁面。**Home** 上的 **+ Top up** 按鈕會開啟同一個頁面。

![Balance 頁面：Available、Held for running work 和 Balance 三個方塊，左邊是 Top up 與 Refund，右邊是 Activity 清單。](/images/account/balance-1.webp)

## 三個方塊

- **Available**：你現在可以花用的 SSU。
- **Held for running work**：建造或 App 呼叫進行期間預留的 SSU。
- **Balance**：你的帳號在平台上持有的 SSU。

## 儲值

**Top up** 會把你錢包裡已有的 SSU 轉到你的平台餘額。頁面會顯示你的 **Wallet balance**。步驟寫在 [取得 SSU](/zh-tw/start/get-ssu/)，那裡也列出其他增加 SSU 的方式：購買，以及兌換課程代碼。

## 退款

**Refund** 會把你尚未花掉的 SSU 退回你連接的錢包。

1. 在 **REFUND AMOUNT** 底下輸入數量，或點選 **Max**。頁面會顯示有多少是 **Available**。
2. 點選 **Request refund**。

你的退款會列在按鈕下方。在你提出退款之前，它會顯示 **No refunds yet.**

## 活動

**Activity** 是你餘額的每一筆變動清單，最新的在前，每一筆都附有 SSU 數量：

- 建造以及你的 App 所使用的平台功能的扣款。
- **Live runtime**，附上 Agent 的名稱和日期，代表 App 上線運作的費用。
- **Top up**、**Course grant** 和 **Refund** 列。

點選 **Load more** 可以看到較舊的資料列。

## 注意事項

- **Top up** 和 **Request refund** 會使用你連接的錢包。它必須是你登入時所用的錢包。如果它在其他網路，頁面會請你切換到 Base mainnet，並提供 **Switch network**。
- 扣款會在你建造期間以及 App 執行期間自動從你的餘額扣除。想知道什麼會花費 SSU，請閱讀 [SSU 是什麼](/zh-tw/account/what-is-ssu/)。
