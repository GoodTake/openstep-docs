好的需求簡短又具體。你可以像我們對咖啡店那樣，從一句話開始，然後一則訊息一則訊息地調整網站。

1. 說明網站是什麼、給誰用。*一家小咖啡店的網站。*
2. 說出頁面，或訪客必須能做的事。*菜單、營業時間，還有一個預約訂位的表單。*
3. 補上你在意的任何事：名稱、語氣、顏色、你真正的菜單與價格、你真正的營業時間。你沒說的部分，builder 會用合理的預設值補上，之後你可以請它修改。
4. 按 Enter 送出訊息。換行請用 Shift + Enter。

![在 New agent 輸入框中輸入的咖啡店需求，尚未送出。](/images/build/start-website-1.webp)

## 一則訊息一則訊息地修改網站

一次提出一個修改，每次之後都看一下 Preview。*讓訂位表單多問一個電話號碼。* *把營業時間改成平日 8:00 到 17:00。* *在菜單加一個週末早午餐的區塊。* 描述你希望訪客看到或做到什麼，而不是怎麼寫程式。

## 加入圖片或 PDF

點選輸入框左下角的 **+**（**Attach file**），或把檔案拖放到輸入框上，或貼上螢幕截圖。你可以附加 JPEG、PNG 和 WebP 圖片以及 PDF 檔，每則訊息最多 5 個。每個檔案會顯示成一個標籤，帶有名稱、大小和一個移除按鈕。如果上傳失敗，標籤會提供 **Retry**。單獨貼上一張螢幕截圖本身就是一則完整的訊息，所以你可以給 builder 看點東西，不加文字就送出。

## 指向頁面上的某個東西

當 Preview 支援時，Preview 工具列會出現一支鉛筆。點選它就會開啟 **Edit mode**，然後點選頁面上的任何元素即可選取。它會以標籤的形式出現在你的訊息上方，所以你可以直接說 *把這個標題縮小一點*，不用解釋它在哪裡。在 **Edit mode** 中，你也可以直接在頁面上修改文字或樣式。**Apply** 按鈕會顯示你做了多少處修改，按下去就保留，**Discard** 則放棄。

## 要求全新的外觀

一般的需求會在目前的設計範圍內修改網站。如果你要求完全不同的外觀，builder 可以在輸入框上方提供 **Redesign the visual style**，並附上一行簡短的文字說明它理解了什麼。點選它就會依該需求進行。

## 注意事項

- 不確定要提什麼？選擇 **Brainstorm**，讓 builder 來問。見 [Build 與 Brainstorm](/zh-tw/build/modes/)。
- builder 工作期間你不能送出訊息。請等到 **Done**，或停止這一輪。見 [追蹤進度](/zh-tw/build/progress/)。
- 你想要的是頁面以外的東西，例如寄送電子郵件或收款？見 [你的網站能做什麼](/zh-tw/build/what-your-site-can-do/)。
