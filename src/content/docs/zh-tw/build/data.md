大多數網站都會儲存一些東西：訂位、訂單、訊息。**Data** 分頁會列出你的網站儲存了什麼，讓你不必請 builder，也能自己查看與修正。

1. 點選右側頂部、**Preview** 旁邊的 **Data**。頁面標題是 **Data**，每個資料表一張卡片，並附上其中的資料筆數。以咖啡店為例，資料表有 **bookings**、**orders** 和 **users**。用 **Search tables…** 尋找，用 **A-Z** 變更排序。
2. 點選一個資料表開啟它。頂部是它的名稱與資料筆數，例如 **bookings (1)**，下面是它的資料列。用 **Search rows…** 篩選，點選欄位標題排序，並用底部的箭頭換頁。
3. 點選一列即可修改，然後點選 **Save changes**。用 **+ Add item** 新增一列。每一列也有一個刪除它的按鈕。
4. 點選左上角的返回箭頭，回到資料表清單。

![Data 分頁中的 bookings 資料表，內有在 Preview 中做的測試訂位。](/images/build/data-1.webp)

## 注意事項

- 螢幕截圖中的訂位，是我們在 [Preview](/zh-tw/build/preview/) 中送出訂位表單時出現的。資料表會隨著人們使用網站而填入內容。
- 這是開發資料：Preview 讀取和寫入的資料。在你[發布](/zh-tw/build/go-live/)之後，線上網站有它自己獨立的資料。在 Preview 中做的測試訂位不會進到線上網站，線上網站上的訂位也不會顯示在這裡。**Publish** 永遠不會把開發資料複製到線上網站。它會保留線上資料與學習者的進度，而且絕不會開啟新的 session。如果更新會移除資料，例如新版本不再有的資料表或欄位，Publish 對話框會先提出警告，以這種方式移除的資料無法復原。
- 你在這裡編輯資料列。要新增資料表或新欄位，請在對話中請 builder 處理。它在建造時會建立資料表。
- 擁有者和編輯者可以修改資料列。檢視者只能看。
