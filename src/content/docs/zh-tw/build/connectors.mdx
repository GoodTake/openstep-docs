Connector 讓你的網站使用你在其他服務的帳號：把訂位寫進 Google Sheet、發訊息到 Slack、開一個 GitHub issue，或在交易所交易。帳號只要連一次，金鑰由平台保管，呼叫也由平台替網站發出。

## 目前可用的 Connector

### 檔案與文件

| 服務 | 網站能做什麼 | 連線方式 |
|---|---|---|
| Google Drive | 讀寫你選的 Sheets 和 Docs | 登入 |
| Lark / 飛書 | 讀寫你選的 Sheets、Docs 和 Bases | 自己的應用，再登入 |

### 日曆

| 服務 | 網站能做什麼 | 連線方式 |
|---|---|---|
| Google Calendar | 讀取、建立、修改你選的日曆裡的活動 | 自己的應用，再登入 |

### 訊息、郵件與社群

| 服務 | 網站能做什麼 | 連線方式 |
|---|---|---|
| Slack | 發訊息到你選的公開頻道 | 登入 |
| Mailchimp | 維護你選的受眾的成員和標籤 | API key |
| LinkedIn | 以你的個人檔案發純文字貼文 | 自己的應用，再登入 |
| Resend | 用你自己的網域寄出網站的信 | API key |

### 銷售與客服

| 服務 | 網站能做什麼 | 連線方式 |
|---|---|---|
| HubSpot | 讀取和管理聯絡人與商機 | 自己的應用，再登入 |
| Zendesk | 讀取、建立和回覆工單 | 自己的應用，再登入 |

### 分析與會計

| 服務 | 網站能做什麼 | 連線方式 |
|---|---|---|
| Google Analytics 4 | 讀取你選的資源的報表 | 自己的應用，再登入 |
| Xero | 讀取你選的組織的會計資料 | 自己的應用，再登入 |

### 開發者工具

| 服務 | 網站能做什麼 | 連線方式 |
|---|---|---|
| GitHub | 讀取 issue 和 pull request，在你選的儲存庫開 issue | Personal access token |

### 交易

| 服務 | 網站能做什麼 | 連線方式 |
|---|---|---|
| Hyperliquid | 永續合約：餘額、持倉、市價與限價單、止盈止損、撤單、平倉 | 用錢包簽一次名，批准一把交易用的金鑰。這把金鑰不能提領。 |
| OKX | 現貨和永續合約：餘額、持倉、下單、行情 | 貼上你 OKX 帳戶的 API key、secret 和 passphrase，建立時只開 Read 和 Trade。能提領的 key 會被拒絕。可選 Demo 或 Live。 |
| Binance | 現貨和 U 本位永續：餘額、持倉、市價與限價單、止盈止損、撤單、平倉 | 貼上你 Binance 帳戶的 API key 和 secret，建立時只開讀取和交易。能提領的 key 會被拒絕。可選 Testnet 或 Live。 |

交易怎麼運作，見下方的[交易 Connector](#交易-connector)。

**自己的應用**：在該服務的開發者設定裡建立一個應用（OAuth client），把它的 ID 和 secret 貼進連線表單。

## 交易 Connector

交易 Connector 讓 builder 和你的網站使用你的交易所帳戶：讀取餘額和持倉、下單、平倉。你在 **Plugins & connections** 連上自己的交易所帳戶：在交易所頁面上或用錢包授權；OKX 和 Binance 則是把你自己帳戶的 API key 貼進連線表單。金鑰不會進到對話或程式碼裡。

<Flow
  numbered
  steps={[
    { title: '點 Connect', text: 'Console → Plugins & connections。' },
    { title: '授權或填入 key', text: '在交易所登入、用錢包簽名，或貼上 API key。' },
    { title: 'OpenStep 連線', text: '把授權結果或 key 加密保存。', highlight: true },
    { title: 'builder 和網站交易', text: '讀餘額、下單、平倉。' },
  ]}
/>

:::caution[下單是真的]
在 Preview 裡，網站用你連線的帳戶交易；在對話裡，你一開口 builder 就可能下單。建造時，交易所有模擬盤或測試網的話盡量用它。
:::

連線顯示 **Needs reconnect** 時，點 **Reconnect** 重新授權。

## 外掛：MCP servers

外掛讓 **builder** 在對話中多一些工具可用，例如查詢合作方服務的資料。外掛由平台加入，Agent 的 owner 在 **Plugins & connections → MCP servers** 裡開啟。平台有提供外掛時才會出現這一區。

## 出問題時

| 你看到 | 怎麼辦 |
|---|---|
| Connections are not available for this agent yet. | Connector 是逐個 Agent 開啟的，請聯絡 OpenStep 團隊。 |
| The connected account stopped working. Reconnect it to continue. | 在 Plugins & connections 點 **Reconnect**。 |
| The app needs more access than the account allowed. | 重新連線，並允許它要求的權限。 |
