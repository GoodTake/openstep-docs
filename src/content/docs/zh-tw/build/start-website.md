網站由 **Web builder** Agent 來建：你描述網站，它把網站建出來。這個章節會跟著一個小網站，從第一則訊息走到上線網址：一家叫 The Cozy Coffee Table 的咖啡店，有菜單、營業時間和訂位表單。

1. 點選左側欄的 **+ New agent**。**New agent** 開啟時，**Based on** 已設為 **Web builder**，並選了 **Build**。
2. 在寫著 **Describe an app, a learning experience, or your next idea…** 的輸入框裡描述網站。咖啡店的例子，我們寫的是：*A website for a small coffee shop: the menu, opening hours, and a form to book a table.*
3. 維持選取 **Build**，模型保持 **Auto**。輸入框下方那一行寫著 **Build changes it directly.**
4. 點選 **Start building →**。

![New agent 頁面，已選好 Web builder、輸入了咖啡店的需求，並選了 Build。](/images/build/start-website-1.webp)

Agent 建立後，它的工作頁會開啟，而你的訊息已經送出。builder 會依你的需求替 Agent 命名；我們的這個變成 The Cozy Coffee Table。因為你選了 **Build**，它會立刻開始：沒有問題，也沒有需要核准的計畫。

它工作時，右側的預覽卡片會依序顯示 **Thinking**、**Planning**、**Writing code**、**Preview & test** 和 **Done**。建造完成後，builder 的最後一則訊息會列出現在可以用的功能。咖啡店的例子是一個首頁、一個菜單頁，以及一個 **Book a table** 頁面，表單會儲存訂位。這個網站的第一次建造花了大約 15 分鐘。

## 注意事項

- 建造會花費 SSU。如果你的餘額是空的，請先[取得一些 SSU](/zh-tw/start/get-ssu/)。
- 你有三種方式可以進入 **New agent**：左側欄的 **+ New agent**、**Home** 上的 **What would you like to build?**，或 Marketplace 中 **Website or app** 卡片上的 **Use this agent →**。在 Marketplace 裡，Web builder 叫做 **Website or app**；在 **New agent** 上，它叫做 **Web builder**。
- builder 會自己挑選菜單、價格和營業時間。它們只是暫代內容：你隨時可以請它修改。
- 還不確定自己要什麼？選擇 **Brainstorm** 而不是 **Build**，builder 會先問你問題。見 [Build 與 Brainstorm](/zh-tw/build/modes/)。
- 第一則訊息的撰寫技巧，請看[描述你想要的東西](/zh-tw/build/describe/)。
