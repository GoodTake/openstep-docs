builder 是靠 AI 模型運作的。預設的 **Auto** 會替每個需求挑最合適的模型，對大多數網站來說這樣就夠了。如果你想自己選，可以在放著模式的同一個選單裡指定模型。

1. 點選輸入框底部的晶片，例如 **Auto · Build**。在 **New agent** 和 **Home** 上，模型控制項 **Auto** 就在 **Build** / **Brainstorm** 切換鈕旁邊。
2. 在 **Select model**（**Choose how STEPS routes this turn**）底下，維持選取 **Auto**（**Best model for each request**），或到 **Choose model**（**Pick a model for this run**）底下，點選清單中的某個模型。
3. 送出你的訊息。它會用晶片現在顯示的模型執行。

![展開的輸入框晶片：Select model 勾選了 Auto，下方是簡短的 Choose model 清單，底部是 Run mode。](/images/build/choose-model-1.webp)

更換模型本身不會啟動任何事。它只會改變你接下來那則訊息的處理方式。

## 注意事項

- **Choose model** 底下的清單會隨時間改變，所以本指南不列出模型名稱。選單永遠會顯示目前可用的模型。
- builder 工作期間，晶片會呈現灰色。請在訊息之間更換模型。
- 如果晶片顯示 **Loading models**，請稍候一下。如果顯示 **Models unavailable**，點選它再試一次。
- 模式也在同一個選單裡。見 [Build 與 Brainstorm](/zh-tw/build/modes/)。
