- 建造是在平台提供的隔離環境中進行。你不需要自己的主機就能開始。
- 如果對話顯示 **This chat got too long**，請再送出一次你的訊息。下一輪會重新開始，而你已經建造的一切都安全無虞。
- Agent 還在建造時不能發布。標題列的 **Publish** 會呈現灰色，直到建造停止。見 [讓網站上線](/zh-tw/build/go-live/)。
- 只有 Agent 的擁有者能發布它、變更誰可以開啟它，以及刪除它。編輯者可以對話與建造，檢視者只能看。見 [與他人協作](/zh-tw/agent/work-with-others/)。
- **Publish** 會讓 Agent 的每個 App 一起上線。只要有一個 App 失敗，就不會有任何改變，線上版本維持原樣。
- 自訂網域請使用當時 **Console** 中 **Domains** 底下顯示的 DNS 目標。每個 App 有自己的網域。見 [網域](/zh-tw/build/domains/)。
- App 上線運作與建造都會花費 SSU。見 [SSU 是什麼](/zh-tw/account/what-is-ssu/)。
- 本站說明的是 builder 產品。請不要把內部工程規格或部署筆記當作使用者文件。
