**為什麼我要簽兩次？**  
先連接你的錢包，再簽署登入請求。第二步不是轉帳：頁面會顯示 **It's free — no transaction, no gas.** 見 [登入](/zh-tw/start/sign-in/)。

**Agent 和 App 有什麼差別？**  
Agent 保存你的對話、它的計畫與它的建造內容。它會建出一個或多個 App，每個 App 都有自己的預覽、程式碼、資料和上線網址。見 [OpenStep 是什麼](/zh-tw/start/what-is/)。

**如何使用現成的 Agent？**  
在 **Marketplace** 挑一個，然後點選 **Use this agent →**。見 [從 Marketplace 挑選 Agent](/zh-tw/agent/pick-agent/) 和 [建立你的第一個 Agent](/zh-tw/start/create-agent/)。

**為什麼 Brainstorm 沒有改我的 App？**  
這是刻意的設計。**Brainstorm** 會提問並擬出計畫，只有在你核准計畫之後才會建造。若要立刻修改 App，請在 **Build** 模式下送出你的訊息。見 [Build 與 Brainstorm](/zh-tw/build/modes/) 和 [核准計畫](/zh-tw/agent/approve-plan/)。

**Preview 和 Publish 有什麼差別？**  
**Preview** 是你的草稿，也就是 App 目前的樣子，在其他人能開啟它之前。**Publish** 會讓 Agent 的每個 App 一起上線，放在其他人可以開啟的網址。見 [預覽你的網站](/zh-tw/build/preview/) 和 [讓網站上線](/zh-tw/build/go-live/)。

**如何讓其他人試用我的 App？**  
發布 Agent，然後把網址傳給他們。你可以在 **Console**、**Settings**、**Access** 選擇誰可以開啟它：任何有連結的人，或僅限學習者。見 [發布與分享](/zh-tw/agent/publish-and-share/)。

**可以用其他貨幣收款嗎？**  
不行。App 內付款只用 SSU。見 [SSU 是什麼](/zh-tw/account/what-is-ssu/)。

**我的 SSU 去哪了？**  
點選左側欄的 **Balance**。**Activity** 列出每一筆扣款：建造、你的 App 所使用的平台功能，以及讓 App 上線運作。見 [查看餘額](/zh-tw/account/balance/)。

**我可以在自己的電腦上處理 Agent 嗎？**  
可以，使用 OpenStep CLI。見 [CLI 能做什麼](/zh-tw/cli/what-it-does/)。
