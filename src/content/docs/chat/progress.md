While a turn is running, a status line appears below the assistant bubble. Typical labels:

- **Preparing** — getting the environment ready
- **Waiting for a free build slot** — the queue is busy
- **Thinking** — the model is working
- **Planning** — writing or updating a plan
- **Building** — changing code
- **Done** — the turn finished
- **Cancelled** — you stopped the turn

You cannot send another message until the current turn finishes or is cancelled. Use **Stop** in the composer to cancel.

If the queue is busy, wait. You do not need to refresh; the page updates on its own.
