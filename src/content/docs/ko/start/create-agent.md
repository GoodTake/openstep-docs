**New agent**에서 Agent를 시작합니다. 무엇을 기반으로 할지 고르고, 구상을 말하고, 시작하면 됩니다. Agent가 만들어지고, 보낸 메시지가 이미 전송된 상태로 작업 페이지가 열립니다.

1. **New agent**를 엽니다. 들어가는 길은 세 가지이며 모두 같은 입력 상자로 이어집니다.
   - 왼쪽 레일에서 **+ New agent**를 클릭합니다.
   - **Home**에서 **What would you like to build?** 상자를 사용합니다.
   - **Marketplace**의 카드에서 **Use this agent →** 버튼을 클릭합니다. **New agent**가 해당 제품이 이미 선택된 상태로 열립니다.
2. **Based on** 아래에서 Agent의 기반을 확인합니다. 기본값은 **Web builder**이며, 설명한 내용으로 웹사이트나 앱을 만듭니다. 준비된 Agent를 쓰려면 **Based on** 메뉴를 열거나 **A great place to start** 아래의 카드, 예를 들어 **Health & fitness**를 클릭합니다.
3. **Describe an app, a learning experience, or your next idea…** 문구가 있는 상자에 원하는 것을 설명합니다. 예를 들면 *I want to get stronger. I can train 3 days a week at the gym, about 45 minutes each time.*
4. **Build** 또는 **Brainstorm**을 고릅니다. 선택한 Agent에 맞는 기본값이 정해집니다. **Web builder**는 **Build**로, **Health & fitness**는 **Brainstorm**으로 시작합니다. 상자 아래 한 줄이 그 모드가 하는 일을 설명합니다. [Build와 Brainstorm](/ko/build/modes/)을 참고하세요.
5. 모델은 **Auto**로 두거나 다른 모델을 고릅니다. [모델 고르기](/ko/build/choose-model/)를 참고하세요.
6. 시작 버튼을 클릭합니다. **Brainstorm**에서는 **Start brainstorming →**, **Build**에서는 **Start building →** 버튼입니다.

![Health & fitness를 고르고 첫 메시지를 입력했으며 Brainstorm이 선택된 New agent 페이지.](/images/start/create-agent-1.webp)

## 알아 두기

- builder가 새 Agent에 이름을 붙입니다. 나중에 **My agents**나 왼쪽 레일의 **RECENT AGENTS** 아래에서 찾을 수 있습니다.
- 빌드에는 SSU가 듭니다. 잔액이 비어 있으면 먼저 [SSU를 받으세요](/ko/start/get-ssu/).
- Marketplace에서는 기본 Agent가 **Website or app**으로 표시됩니다. **New agent**에서는 같은 Agent를 **Web builder**라고 부릅니다.
