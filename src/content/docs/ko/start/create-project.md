로그인한 뒤 왼쪽 레일에서 **New project**를 고르거나 `/projects/new`를 엽니다.

제목은 **What do you want to create?**이고, 부제는 **Describe your idea, or start from an example.**입니다.

1. 상자에 시스템을 설명합니다(비워 두고 나중에 말해도 됩니다).
2. 세그먼트 **Run mode**에서 **Build** 또는 **Brainstorm**을 고를 수 있습니다(기본은 Build). **Brainstorm**은 질문만 하고 코드를 쓰지 않습니다. **Build**는 프로젝트에 코드를 씁니다. [Build와 Brainstorm](/ko/chat/modes/)을 보세요.
3. 모델 선택기에서 모델을 바꿀 수 있습니다.
4. 위쪽 화살표(접근성 이름 **Create project**)를 누르거나 Enter(줄바꿈은 Shift+Enter).

예시 칩은 프롬프트를 채웁니다. 예: **Habit tracker web app**, **Launch a token**, **Token with a claim page**.

성공하면 프로젝트 편집기(`/projects/:id`)가 열립니다. 만들 때 설명을 적었다면 첫 채팅으로 보내집니다.
