OpenStep은 AI 풀스택 빌더입니다. [builder.openstep.academy](https://builder.openstep.academy)에서 채팅으로 원하는 시스템을 설명하면, 플랫폼이 격리된 환경에서 구축합니다. 미리보기와 게시가 가능합니다.

처음부터 서버나 git 저장소가 필요하지 않습니다. 제품을 열고, 지갑으로 로그인한 뒤, 프로젝트를 만들고, 원하는 것을 말하면 됩니다.

이 사이트는 **OpenStep builder 사용 방법**을 다룹니다. 게시한 앱이 할 수 있는 일(결제, 이메일, 데이터 저장)은 「앱 만들기」의 짧은 개요이며 API 목록이 아닙니다.
