OpenStep은 대화를 동작하는 앱으로 바꿔 줍니다. Agent를 시작하고 필요한 것을 말하면, Agent가 하나 이상의 앱을 만들고, [builder.openstep.academy](https://builder.openstep.academy)에서 이를 미리 보고 게시할 수 있습니다.

Agent는 대화와 빌드를 한곳에 모아 두며, 여러 앱을 만들 수 있습니다. **Publish**는 그 앱을 모두 함께 라이브로 올립니다.

각 부분의 설명과 세 가지 가이드 스토리는 [시스템 개요](/ko/how-it-works/system-overview/)에서, Agent가 무엇으로 이루어져 있는지는 [Agent 내부](/ko/how-it-works/inside-an-agent/)에서 볼 수 있습니다.

## 작업 중인 Agent

Health & fitness Agent의 모습입니다. 왼쪽에는 대화와 계획이, 오른쪽에는 Agent가 만든 앱이 있습니다.

![Health & fitness Agent의 작업 페이지: 왼쪽에 채팅과 계획, 오른쪽에 앱.](/images/start/what-is-1.webp)

## 자주 보게 될 용어

| 용어 | 의미 |
| --- | --- |
| **Agent** | 만들어서 계속 작업하는 대상: 대화, 빌드, 그리고 앱. |
| **App** | Agent 안의 사이트 하나. 자체 미리보기, 코드, 데이터, 라이브 링크가 있습니다. |
| **Marketplace** | 바로 시작할 수 있는 준비된 Agent 목록. |
| **Brainstorm** / **Build** | 작업 방식 두 가지. **Brainstorm**은 먼저 질문하고 계획을 세우며, **Build**는 앱을 바로 바꿉니다. |
| **Publish** | Agent의 모든 앱을 함께 라이브로 올립니다. |
| **SSU** | 빌드와 앱 기능을 쓸 때 소비되는 것. [SSU 받기](/ko/start/get-ssu/)를 참고하세요. |

## 첫 메시지를 보낸 뒤에는

<ol class="flow not-content">
  <li>Agent가 몇 가지를 묻습니다</li>
  <li>계획을 승인합니다</li>
  <li>작업별로 빌드합니다</li>
  <li>**Preview**에서 직접 써 봅니다</li>
  <li>**Publish**하고 공유합니다</li>
</ol>

이것은 **Brainstorm** 경로입니다. **Build** 모드에서는 질문도 승인할 계획도 없이, Agent가 바로 앱을 바꾸기 시작합니다.
