**왜 두 번 서명하나요?**  
먼저 지갑을 연결하고, 그다음 로그인 요청에 서명합니다. 두 번째는 송금이 아닙니다. 페이지에 **no transaction, no gas**라고 적혀 있습니다.

**Brainstorm이 앱을 바꾸지 않는 이유는?**  
설계입니다. Brainstorm은 논의만 합니다. 코드를 쓰려면 **Start building**을 누르세요.

**Preview와 Publish의 차이는?**  
Preview는 편집 중인 초안입니다. Publish가 어떤 버전을 다른 사람이 열 수 있는 URL로 올립니다.

**다른 통화로 결제받을 수 있나요?**  
없습니다. 앱 내 결제는 SSU만 가능합니다.

**Agents는 어떻게 쓰나요?**  
아직 개발 중입니다. [Agents](/ko/agent/pick-agent/)를 보세요.
