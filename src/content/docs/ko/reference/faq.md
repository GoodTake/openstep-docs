**왜 두 번 서명하나요?**  
먼저 지갑이 연결되고, 그다음 로그인 요청에 서명합니다. 두 번째 단계는 송금이 아닙니다. 페이지에 **It's free — no transaction, no gas.** 문구가 나옵니다. [로그인](/ko/start/sign-in/)을 참고하세요.

**Agent와 앱은 무엇이 다른가요?**  
Agent는 대화, 계획, 빌드를 담고 있습니다. Agent가 앱을 하나 이상 만들고, 각 앱에는 자체 미리보기, 코드, 데이터, 라이브 주소가 있습니다. [OpenStep이란](/ko/start/what-is/) 페이지를 참고하세요.

**준비된 Agent는 어떻게 쓰나요?**  
**Marketplace**에서 하나를 골라 **Use this agent →** 버튼을 클릭합니다. [Marketplace에서 Agent 고르기](/ko/agent/pick-agent/)와 [첫 Agent 만들기](/ko/start/create-agent/)를 참고하세요.

**Brainstorm이 왜 내 앱을 바꾸지 않았나요?**  
의도된 동작입니다. **Brainstorm**은 질문하고 계획 초안을 만들며, 계획을 승인한 뒤에만 빌드합니다. 앱을 바로 바꾸려면 **Build** 모드로 메시지를 보내세요. [Build와 Brainstorm](/ko/build/modes/)과 [계획 승인하기](/ko/agent/approve-plan/)를 참고하세요.

**Preview와 Publish는 무엇이 다른가요?**  
**Preview**는 초안, 즉 다른 사람이 열 수 있기 전의 현재 앱입니다. **Publish**는 Agent의 모든 앱을 다른 사람이 열 수 있는 주소에 함께 라이브로 올립니다. [사이트 미리보기](/ko/build/preview/)와 [라이브로 전환하기](/ko/build/go-live/)를 참고하세요.

**다른 사람이 내 앱을 써 보게 하려면 어떻게 하나요?**  
Agent를 게시한 뒤 주소를 보냅니다. 링크가 있는 누구나 열 수 있게 할지, 학습자만 열 수 있게 할지는 **Console**, **Settings**, **Access**에서 정합니다. [게시와 공유](/ko/agent/publish-and-share/)를 참고하세요.

**다른 통화로 결제를 받을 수 있나요?**  
아니요. 앱 내 결제는 SSU만 가능합니다. [SSU란](/ko/account/what-is-ssu/) 페이지를 참고하세요.

**내 SSU는 어디로 갔나요?**  
왼쪽 레일의 **Balance**를 클릭합니다. **Activity**에 빌드, 앱이 쓰는 플랫폼 기능, 앱의 라이브 운영에 대한 모든 차감이 나열됩니다. [잔액 확인](/ko/account/balance/)을 참고하세요.

**내 컴퓨터에서 Agent를 작업할 수 있나요?**  
네, OpenStep CLI로 할 수 있습니다. [CLI가 하는 일](/ko/cli/what-it-does/)을 참고하세요.
