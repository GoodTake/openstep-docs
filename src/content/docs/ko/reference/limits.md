title: 플랫폼 안내
description: OpenStep을 쓸 때 알아야 할 제품 경계.
sidebar:
  order: 2
---

- 구축은 플랫폼이 제공하는 격리 환경에서 이루어집니다. 시작하려고 직접 호스트를 둘 필요는 없습니다.
- 대화가 너무 길어지면 새 채팅을 시작하세요. 프로젝트는 그대로입니다.
- AI가 아직 **Building**이면 게시할 수 없습니다. 턴이 끝날 때까지 기다리세요.
- 커스텀 도메인은 그때 해당 프로젝트 **Domains** 패널에 나온 DNS 대상을 쓰세요.
- 이 사이트는 builder 제품 조작을 다룹니다. 내부 엔지니어링 명세나 배포 기록을 사용자 문서로 쓰지 마세요.
