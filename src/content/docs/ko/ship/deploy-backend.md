---
title: 백엔드 배포
description: Console → Deploy에서 프로젝트 백엔드를 배포합니다.
sidebar:
  order: 2
---

백엔드가 있는 프로젝트만 Console → APP에 **Deploy**가 나타납니다.

연 뒤 **Deploy backend (Development)**를 누릅니다. 성공하면 배포된 서브도메인(예: **Backend deployed: …**)이 표시됩니다. 백엔드가 없는 프로젝트에는 이 항목이 없습니다.

미리보기와 백엔드 배포는 다릅니다. 웹 UI는 먼저 **Preview**에서 볼 수 있고, 백엔드가 API를 제공해야 할 때 Deploy를 씁니다.
