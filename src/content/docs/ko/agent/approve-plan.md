title: 계획 확정

  order: 3
---

Brainstorm 턴이 계획으로 끝나면, 마지막 어시스턴트 메시지 아래에 두 동작이 나타납니다.

- **Start building** — 다음 턴이 **Build**로 실행되며 계획에서 코드를 씁니다.
- **or keep refining** — **Brainstorm**에 남아 대화를 이어갑니다.

이 확인은 Brainstorm 이후에만 나타나고, Build 턴 이후에는 나타나지 않습니다.

확인을 건너뛰고 Brainstorm 상태에서 새 메시지를 보내면, AI는 계속 질문하고 코드는 쓰지 않습니다.
