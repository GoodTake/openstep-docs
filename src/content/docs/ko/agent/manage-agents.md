왼쪽 레일 **Settings**는 `/projects/settings`를 엽니다(프로젝트 안에서는 `/projects/:id/settings` — 같은 워크스페이스 설정).

여기서 할 수 있는 일:

- 워크스페이스 이름 변경(개인 워크스페이스는 바꿀 수 없음)
- **Transfer ownership**으로 이미 워크스페이스에 있는 다른 멤버에게 소유권 이전
- **Delete workspace**로 워크스페이스 삭제(안내에 따라 이름 확인)

프로젝트 수준의 게시, 도메인, 코드는 이 페이지가 아니라 해당 프로젝트의 **Console**에 있습니다.
