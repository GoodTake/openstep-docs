title: 코드 사용
description: /redeem에서 코스 코드를 사용해 워크스페이스와 첨부 SSU를 잠금 해제합니다.
sidebar:
  order: 3
---

`/redeem`을 열거나 로그인 페이지의 **Have a course code? Redeem it →**로 들어갑니다. 제목은 **Redeem your course code**입니다.

1. **Course code**에 `STEPS-ABCD-EFGH-IJKL` 형태의 코드를 입력합니다.
2. 페이지가 먼저 코드를 확인합니다. 로그인하지 않았다면 지갑을 연결해 받습니다.
3. 성공하면 해당 워크스페이스가 잠금 해제되고 코드에 붙은 SSU를 받습니다.

프로젝트가 먼저 필요하지 않습니다. 코드가 잘못되었거나 다른 지갑이 이미 썼거나 잠시 쓸 수 없으면 페이지가 이유를 바로 보여줍니다.
