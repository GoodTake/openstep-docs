대부분의 사이트는 예약, 주문, 메시지처럼 무언가를 저장합니다. **Data** 탭에는 사이트가 저장한 내용이 나열되어, builder에게 요청하지 않고도 직접 보고 고칠 수 있습니다.

1. 오른쪽 위에서 **Preview** 옆의 **Data**를 클릭합니다. 페이지 제목은 **Data**이고, 테이블마다 카드가 하나씩 있으며 항목 수가 함께 표시됩니다. 커피숍의 테이블은 **bookings**, **orders**, **users**입니다. 테이블을 찾으려면 **Search tables…** 상자를, 정렬 순서를 바꾸려면 **A-Z**를 사용합니다.
2. 테이블을 클릭해 엽니다. 맨 위에 이름과 항목 수가 표시되고(예: **bookings (1)**), 그 아래에 행이 나옵니다. 행을 거르려면 **Search rows…** 상자를 사용하고, 열 제목을 클릭하면 정렬되며, 아래쪽 화살표로 페이지를 넘깁니다.
3. 행을 클릭해 수정한 뒤 **Save changes**를 클릭합니다. 행을 추가하려면 **+ Add item**을 사용합니다. 각 행에는 삭제 버튼도 있습니다.
4. 왼쪽 위의 뒤로 가기 화살표를 클릭하면 테이블 목록으로 돌아갑니다.

![Data 탭의 bookings 테이블. Preview에서 만든 테스트 예약이 있음.](/images/build/data-1.webp)

## 알아 두기

- 스크린샷의 예약은 [Preview](/ko/build/preview/)에서 예약 양식을 제출했을 때 나타난 것입니다. 사람들이 사이트를 쓰는 만큼 테이블이 채워집니다.
- 이것은 개발 데이터, 즉 Preview가 읽고 쓰는 데이터입니다. [게시](/ko/build/go-live/)한 뒤의 라이브 사이트는 별도의 자체 데이터를 가집니다. Preview에서 만든 테스트 예약은 라이브 사이트에 반영되지 않고, 라이브 사이트에서 만든 예약은 여기에 나타나지 않습니다. **Publish**는 개발 데이터를 라이브 사이트로 복사하지 않으며 라이브 데이터를 지우지도 않습니다.
- 여기서는 행을 수정합니다. 테이블이나 새 필드를 추가하려면 채팅에서 builder에게 요청하세요. builder는 빌드하면서 테이블을 만듭니다.
- 소유자와 편집자는 행을 바꿀 수 있습니다. 뷰어는 볼 수만 있습니다.
