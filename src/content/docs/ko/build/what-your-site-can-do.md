구축한 앱은 플랫폼 기능 집합을 사용할 수 있습니다. 아래 표는 지도이며 **개발 핸드북이 아닙니다**. 원하는 것은 채팅으로 말하세요. 내부 메서드 이름을 찾지 마세요.

| 하고 싶은 일 | 지원 |
|---|---|
| 앱에서 AI 호출 | 예 |
| 사용자에게 이메일 보내기 | 예 |
| 앱에서 결제 받기 | 예, SSU만 |
| 온체인 컨트랙트와 상호작용 | 예 |
| 사용자가 지갑으로 앱에 로그인 | 예 |
| 업무 데이터 저장 | 예 — [앱 데이터](/ko/build/data/) 참고 |

앱 내 결제에 다른 경로는 없습니다. builder에게 외부 결제 연동을 요청하지 마세요.
