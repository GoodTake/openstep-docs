웹사이트는 **Web builder** Agent가 만듭니다. 사이트를 설명하면 Agent가 만들어 줍니다. 이 섹션은 작은 사이트 하나를 첫 메시지부터 라이브 주소까지 따라갑니다. 메뉴, 영업시간, 테이블 예약 양식이 있는 The Cozy Coffee Table이라는 커피숍입니다.

1. 왼쪽 레일에서 **+ New agent**를 클릭합니다. **New agent**가 열리며 **Based on**이 **Web builder**로, 모드가 **Build**로 선택되어 있습니다.
2. **Describe an app, a learning experience, or your next idea…** 문구가 있는 상자에 사이트를 설명합니다. 커피숍에는 이렇게 썼습니다. *A website for a small coffee shop: the menu, opening hours, and a form to book a table.*
3. **Build**를 그대로 두고 모델도 **Auto**로 둡니다. 상자 아래 한 줄에 **Build changes it directly.** 문구가 나타납니다.
4. **Start building →** 버튼을 클릭합니다.

![Web builder를 고르고 커피숍 요청을 입력했으며 Build가 선택된 New agent 페이지.](/images/build/start-website-1.webp)

Agent가 만들어지고, 메시지가 이미 전송된 상태로 작업 페이지가 열립니다. builder는 요청을 바탕으로 Agent의 이름을 짓습니다. 이번에는 The Cozy Coffee Table이 되었습니다. **Build**를 골랐으므로 질문도 승인할 계획도 없이 바로 시작합니다.

작업하는 동안 오른쪽의 미리보기 카드가 **Thinking**, **Planning**, **Writing code**, **Preview & test**, **Done** 순서로 넘어갑니다. 빌드가 끝나면 builder의 마지막 메시지에 이제 동작하는 것들이 나열됩니다. 커피숍은 홈 페이지, 메뉴 페이지, 그리고 양식이 예약을 저장하는 **Book a table** 페이지였습니다. 이 사이트의 첫 빌드에는 약 15분이 걸렸습니다.

## 알아 두기

- 빌드에는 SSU가 듭니다. 잔액이 비어 있으면 먼저 [SSU를 받으세요](/ko/start/get-ssu/).
- **New agent**에는 세 가지 방법으로 들어갈 수 있습니다. 왼쪽 레일의 **+ New agent**, **Home**의 **What would you like to build?**, 그리고 Marketplace의 **Website or app** 카드에 있는 **Use this agent →** 버튼입니다. Marketplace에서는 Web builder를 **Website or app**이라고 부르고, **New agent**에서는 **Web builder**라고 부릅니다.
- builder는 메뉴, 가격, 영업시간을 자체적으로 정합니다. 임시 값이므로 언제든 바꿔 달라고 요청하세요.
- 아직 무엇을 원하는지 확실하지 않나요? **Build** 대신 **Brainstorm**을 고르면 builder가 먼저 질문합니다. [Build와 Brainstorm](/ko/build/modes/)을 참고하세요.
- 첫 메시지를 쓰는 요령은 [원하는 것을 설명하기](/ko/build/describe/)에 있습니다.
