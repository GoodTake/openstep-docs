프로젝트가 열리면 왼쪽이 채팅입니다. 웹 앱이 있으면 오른쪽은 보통 **Preview**입니다.

만들 때 설명을 적었다면 첫 턴이 시작됩니다. 아니면 원하는 것을 적고 Enter를 누르세요.

첫 턴에서 다음을 말하세요.

- 누구를 위한 것인지, 한 문장
- 처음에 보이는 화면
- 꼭 필요한 화면이나 동작(예: 토큰 클레임, 체크인)

어시스턴트 말풍선 아래에 **Thinking**, **Planning**, **Building** 같은 상태 줄이 나옵니다. 열 수 있으면 Preview에 앱이 보입니다.

**Brainstorm**에서는 AI가 질문하거나 계획을 제안하고 코드는 바꾸지 않습니다. 계획이 맞으면 **Start building**을 누르세요. [계획 확정](/ko/agent/approve-plan/)을 보세요.
