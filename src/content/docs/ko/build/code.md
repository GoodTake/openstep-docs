사이트를 만들기 위해 코드를 읽을 필요는 없지만, 읽을 수는 있습니다. **Code**에는 builder가 쓴 파일이 나오므로 무엇을 바꿨는지 확인할 수 있습니다.

1. 헤더에서 **Console**을 클릭한 다음 **Code**를 클릭합니다. 헤더의 앱 전환기에서 고른 앱의 파일이 표시됩니다.
2. **FILES** 아래의 폴더를 열고 파일을 클릭합니다. 커피숍에는 `migrations`, `public`, `scripts`, `src` 폴더가 있고, `src/App.tsx`에 사이트의 페이지가 나열되어 있습니다.
3. 오른쪽 에디터에서 파일을 읽습니다. 파일은 탭으로 열리며, 열려 있는 파일의 경로가 맨 위에 표시됩니다.
4. **Back to Console**을 클릭하면 다른 Console 섹션으로 돌아갑니다.

![The Cozy Coffee Table의 Console → Code: 왼쪽에 FILES 트리, 읽기 전용 에디터에 src/App.tsx가 열려 있음.](/images/build/code-1.webp)

에디터 위의 도구 모음에는 **Files**, **Quick Open**, **Search**, **Refresh**, **Copy path**, **Copy content**, **Download file**, **Copy link** 버튼이 있습니다.

## 알아 두기

- Code는 읽기 전용입니다. 사이트를 바꾸려면 왼쪽 채팅에서 요청하세요. [원하는 것을 설명하기](/ko/build/describe/)를 참고하세요.
- **Copy path**는 builder에게 특정 파일을 가리킬 때 편리합니다. 경로를 메시지에 붙여 넣으세요.
- **Refresh**는 파일 목록을 다시 불러옵니다. 예를 들어 builder가 파일을 추가한 뒤에 씁니다.
- Code에는 Preview와 같은 초안이 표시되며, 라이브 상태가 아닙니다.
