턴이 진행 중이면 어시스턴트 말풍선 아래에 상태 줄이 나타납니다. 흔한 라벨:

- **Preparing** — 환경을 준비하는 중
- **Waiting for a free build slot** — 대기열이 바쁨
- **Thinking** — 모델이 작업 중
- **Planning** — 계획을 쓰거나 업데이트
- **Building** — 코드를 바꾸는 중
- **Done** — 턴 완료
- **Cancelled** — 턴을 중지함

현재 턴이 끝나거나 취소되기 전에는 다른 메시지를 보낼 수 없습니다. 입력란의 **Stop**으로 취소하세요.

대기열이 바쁘면 기다리세요. 새로고침할 필요는 없습니다. 페이지가 스스로 갱신됩니다.
