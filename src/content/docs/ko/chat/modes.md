**Run mode**는 **Build** 또는 **Brainstorm**입니다.

- **Build** — AI가 프로젝트 코드를 쓰고 바꿉니다. 동작하는 앱이 필요할 때 사용하세요.
- **Brainstorm** — AI가 질문하고 계획을 제안합니다. 코드는 쓰지 않습니다. 아이디어가 아직 열려 있을 때 사용하세요.

**어디서 바꾸나**

- `/projects/new`에서는 세그먼트 **Run mode**가 모델 선택기 옆에 있습니다.
- 편집기에서는 상단 바의 **Run configuration**을 열고 드롭다운에서 **Run mode**를 바꿉니다. 편집기에는 세그먼트 컨트롤이 없습니다.

턴 사이에 모드를 바꿀 수 있습니다. 턴이 진행 중일 때는 바꿀 수 없습니다.

Brainstorm이 계획을 낸 뒤 **Start building**으로 확정하세요. [계획 확정](/ko/chat/confirm-plan/)을 보세요.
