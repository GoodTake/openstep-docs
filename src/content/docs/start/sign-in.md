Open [builder.openstep.academy](https://builder.openstep.academy). If you are not signed in, you land on `/login`.

There is no username or password. The sign-in title is **Sign in**, with **No password — your wallet is your account.**

1. Pick a wallet (installed wallets are listed).
2. Approve the connection in the wallet. The UI shows **Opening …** / **Approve the connection in your wallet.**
3. Approve a signature request. The UI shows **Finish in …** and **It's free — no transaction, no gas.**

After the signature is verified you go to the project list (`/projects`). If you were sent to sign-in from another page, you return there.

OpenStep runs on **Base**. If the wallet is on another network, the page says **STEPS runs on Base. Switch, and we'll pick up where you left off.** Switch to Base and continue.

Below the form, **Have a course code? Redeem it →** opens the redemption page. See [Redeem a code](/account/redeem/).
