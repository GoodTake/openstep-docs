When the project opens, chat is on the left. The right side is usually **Preview** if the project includes a web app.

If you already wrote a description when creating the project, the first turn starts. Otherwise type what you want in the composer and press Enter.

In the first turn, say:

- Who it is for, in one sentence
- What they see first
- Any must-have screens or actions (for example “claim tokens” or “check in”)

Below the assistant bubble a status line appears, such as **Thinking**, **Planning**, or **Building**. Preview shows the app when it can open.

In **Brainstorm**, the AI asks questions or proposes a plan and does not change code. When the plan looks right, click **Start building**. See [Confirm the plan](/chat/confirm-plan/).
