After you sign in, choose **New project** in the left rail, or open `/projects/new`.

The heading is **What do you want to create?** The subtitle is **Describe your idea, or start from an example.**

1. Describe the system in the box (you can also leave it empty and talk later).
2. Optionally pick **Build** or **Brainstorm** with the segmented **Run mode** control (default is Build). **Brainstorm** asks questions and writes no code; **Build** writes code in the project. See [Build and Brainstorm](/chat/modes/).
3. Optionally change the model in the model selector.
4. Click the up-arrow button (accessible name **Create project**) or press Enter (Shift+Enter for a new line).

Example chips fill in a prompt, such as **Habit tracker web app**, **Launch a token**, and **Token with a claim page**.

On success you open the project editor (`/projects/:id`). If you typed a description, it is sent as the first chat turn.
