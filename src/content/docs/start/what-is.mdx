OpenStep turns a conversation into a working app. You start an agent, tell it what you need, and it builds one or more apps that you can preview and publish at [builder.openstep.academy](https://builder.openstep.academy).

## How the pieces fit

<div class="how-fits not-content">
  <div class="node"><b>You</b><small>describe, answer, approve</small></div>
  <span class="arrow" aria-hidden="true">→</span>
  <div class="node accent"><b>Agent</b><small>conversation · plan · builds</small></div>
  <span class="arrow" aria-hidden="true">→</span>
  <div class="stack">
    <div class="node"><b>App</b><small>preview · code · data</small></div>
    <div class="node"><b>App</b><small>as many as needed</small></div>
  </div>
  <span class="arrow" aria-hidden="true">→</span>
  <div class="node"><b>Live link</b><small>after Publish</small></div>
</div>

An agent keeps your conversation and its builds in one place, and can build several apps for you. **Publish** puts all of them live together.

## Words you will see

| Word | What it means |
| --- | --- |
| Agent | What you create and keep working on: the conversation, its builds and its apps. |
| App | One site inside an agent, with its own preview, code, data and live link. |
| **Marketplace** | The list of ready-made agents you can start from. |
| **Brainstorm** / **Build** | Two ways to work. **Brainstorm** asks questions and makes a plan first; **Build** changes your apps right away. |
| **Publish** | Puts every app of the agent live together. |
| SSU | What building and app features spend. See [Get SSU](/start/get-ssu/). |

## What happens after your first message

<ol class="flow not-content">
  <li>The agent asks a few questions</li>
  <li>You approve its plan</li>
  <li>It builds, task by task</li>
  <li>You try it in **Preview**</li>
  <li>You **Publish** and share</li>
</ol>

This is the **Brainstorm** path. In **Build** mode there are no questions and no plan to approve: the agent starts changing your apps right away.
