OpenStep is an AI full-stack builder. At [builder.openstep.academy](https://builder.openstep.academy) you describe the system you want in chat, and the platform builds it in an isolated environment — ready to preview and to publish.

You do not need your own server or git repository first. Open the product, sign in with a wallet, create a project, and say what you want.

This site covers **how to use the OpenStep builder**. What your published app can do (take payment, send email, store data) is a short overview under Build your app — not an API catalog.
