You start an agent on **New agent**: choose what it is based on, tell it what you have in mind, and start. The agent is created and its work page opens with your message already sent.

1. Open **New agent**. There are three ways in, and they all lead to the same box:
   - Click **+ New agent** in the left rail.
   - Use **What would you like to build?** on **Home**.
   - Click **Use this agent →** on a card in the **Marketplace**. **New agent** opens with that product already picked.
2. Under **Based on**, check what the agent is based on. It shows **Web builder** by default, which builds a website or app from what you describe. To use a ready-made agent instead, open the **Based on** menu or click a card under **A great place to start**, such as **Health & fitness**.
3. Describe what you want in the box that says **Describe an app, a learning experience, or your next idea…**. For example: *I want to get stronger. I can train 3 days a week at the gym, about 45 minutes each time.*
4. Choose **Build** or **Brainstorm**. The page picks a default for the agent you chose: **Web builder** starts in **Build**, and **Health & fitness** starts in **Brainstorm**. The line under the box says what the mode does. See [Build and Brainstorm](/build/modes/).
5. Leave the model on **Auto**, or pick another one. See [Choose a model](/build/choose-model/).
6. Click the start button. It reads **Start brainstorming →** in **Brainstorm** and **Start building →** in **Build**.

![The New agent page with Health & fitness picked, a first message typed and Brainstorm selected.](/images/start/create-agent-1.webp)

## Good to know

- The builder gives the new agent a name. You can find it later in **My agents**, or under **RECENT AGENTS** in the left rail.
- Building spends SSU. If your balance is empty, [get some SSU](/start/get-ssu/) first.
- In the Marketplace, the default agent is listed as **Website or app**. On **New agent** the same agent is called **Web builder**.
